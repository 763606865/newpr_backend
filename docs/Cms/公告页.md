# 公告页

## 1) 公告页内容（分页）

- 接口: `GET /cms/announcements`
- 鉴权: 无
- Query 参数:
  - `city_code`（可选，string）：城市编码，取值见 `GET /cms/meta` 地区树中**市级**节点 `code`
  - `tag_ids`（可选，array|string）：标签 ID 列表。支持数组形式（`tag_ids[]=1&tag_ids[]=2`）或逗号分隔字符串（`tag_ids=1,2`）。取值见 `GET /cms/meta` 标签树中叶子节点 `id`
  - `tags_match`（可选，string）：标签匹配方式，默认 `all`
    - `all`：公告须**同时包含**全部指定标签
    - `any`：公告包含**任一**指定标签即可
  - `publisher_types`（可选，array|string）：发布人类型列表。支持数组形式（`publisher_types[]=4&publisher_types[]=5`）或逗号分隔字符串（`publisher_types=4,5`）。取值见 `GET /cms/meta` 返回的 `announcement_publisher_types`
  - `page`（可选，int），默认 `1`
  - `per_page`（可选，int），默认 `15`，范围 `1 ~ 50`

### 发布人类型枚举（`publisher_types`）

| value | label |
|-------|-------|
| `0` | 系统 |
| `1` | 国有企业 |
| `2` | 中央企业 |
| `3` | 事业单位 |
| `4` | 政府机关 |
| `5` | 银行 |
| `6` | 学校 |
| `7` | 民营企业 |
| `8` | 外资企业 |
| `9` | 合资企业 |
| `10` | 医院 |
| `11` | 科研院所 |
| `12` | 行业协会 |
| `13` | 社会组织 |
| `14` | 上市公司 |
| `15` | 非营利组织 |
| `16` | 军队 |
| `99` | 其他 |

### 请求示例

```http
GET /cms/announcements?city_code=360100&tag_ids[]=1&tag_ids[]=2&tags_match=all&page=1&per_page=15
GET /cms/announcements?tag_ids=3,4&tags_match=any
GET /cms/announcements?publisher_types=4,5
GET /cms/announcements?city_code=360100&publisher_types[]=5&tag_ids[]=1
```

### 规则

- 查询条件: `enabled()` + `forCity(city_code)`；传入 `tag_ids` 时额外按标签过滤；传入 `publisher_types` 时按发布人类型过滤
- 标签过滤：基于 `cms_tag_relations` 关联表，通过 `withTags()` 实现
- `tags_match=all` 时，公告关联的标签须覆盖 `tag_ids` 中的全部 ID
- `tags_match=any` 时，公告关联的标签与 `tag_ids` 存在交集即可
- `publisher_types` 为 OR 关系：公告 `publisher_type` 命中列表中任一值即可
- `tag_ids`、`publisher_types` 传入非法值时返回 `422`
- 排序: `is_top desc -> sort asc -> published_at desc`
- 分页: `per_page` 默认 `15`，最大 `50`
- 列表字段: `id`、`city_code`、`title`、`sub_title`、`summary`、`link_url`、`type`、`source_name`、`published_at`、`is_top`

## 2) 公告详情

- 接口: `GET /cms/announcements/{id}`
- 鉴权: 无
- Path 参数:
  - `id`（必填，int）：公告 ID
- Query 参数:
  - `city_code`（可选，string）：城市编码，规则同列表接口

### 返回示例

```json
{
  "code": 200,
  "data": {
    "id": 300,
    "city_code": null,
    "title": "系统公告标题",
    "sub_title": "系统公告副标题",
    "link_url": null,
    "type": 1,
    "source_name": "官网",
    "source_url": "https://example.com",
    "summary": "这是摘要",
    "content": "<p>公告正文</p>",
    "published_at": "2026-05-29 10:00:00",
    "start_at": null,
    "end_at": null,
    "is_top": true,
    "status": 2,
    "sort": 0,
    "extra": [],
    "created_at": "2026-05-29 10:00:00",
    "updated_at": "2026-05-29 10:00:00"
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 规则

- 详情仅返回满足以下条件的数据：
  - `enabled()`（`status = 2` 已发布）
  - `forCity(city_code)`
  - `id = {id}`
- 不存在或不满足条件返回 `404`
- 详情接口当前**不支持** `tag_ids`、`publisher_types` 筛选；筛选请使用列表接口

---

## 3) 前端使用建议

- 公告页筛选器中的标签选项，建议从 `GET /cms/meta` 或 `GET /cms/meta/tags` 加载并本地缓存
- 发布人类型选项从 `GET /cms/meta` 的 `announcement_publisher_types` 加载
- 多选标签且要求“同时满足”时传 `tags_match=all`；要求“命中任一”时传 `tags_match=any`
- `city_code`、`tag_ids`、`publisher_types` 可组合使用，例如按城市 + 银行/政府 + 招考标签筛选公告
