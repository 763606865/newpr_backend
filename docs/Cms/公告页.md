# 公告页

## 1) 公告页内容（分页）

- 接口: `GET /cms/announcements`
- 鉴权: 无
- Query 参数:
  - `city_code`（可选，string）
  - `page`（可选，int），默认 `1`
  - `per_page`（可选，int），默认 `15`，范围 `1 ~ 50`

### 返回示例

```json
{
  "code": 200,
  "data": {
    "current_page": 1,
    "data": [
      {
        "id": 300,
        "city_code": null,
        "title": "系统公告标题",
        "sub_title": "系统公告副标题",
        "summary": "公告摘要",
        "link_url": null,
        "type": 1,
        "source_name": "官网",
        "published_at": "2026-05-29 10:00:00",
        "is_top": true
      }
    ],
    "first_page_url": "http://local.newpr_backend.com/cms/announcements?page=1",
    "from": 1,
    "last_page": 10,
    "last_page_url": "http://local.newpr_backend.com/cms/announcements?page=10",
    "next_page_url": "http://local.newpr_backend.com/cms/announcements?page=2",
    "path": "http://local.newpr_backend.com/cms/announcements",
    "per_page": 15,
    "prev_page_url": null,
    "to": 15,
    "total": 150
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 规则

- 查询条件: `enabled()` + `forCity(city_code)`
- 排序: `is_top desc -> sort asc -> published_at desc`
- 分页: `per_page` 默认 `15`，最大 `50`
- 列表字段: `id`、`city_code`、`title`、`sub_title`、`summary`、`link_url`、`type`、`source_name`、`published_at`、`is_top`

## 2) 公告详情

- 接口: `GET /cms/announcements/{id}`
- 鉴权: 无
- Path 参数:
  - `id`（必填，int）
- Query 参数:
  - `city_code`（可选，string）

### 返回示例

```json
{
  "code": 200,
  "data": {
    "id": 300,
    "city_code": null,
    "title": "系统公告标题",
    "sub_title": "系统公告副标题",
    "link_url": null,
    "type": 1,
    "source_name": "官网",
    "source_url": "https://example.com",
    "summary": "这是摘要",
    "content": "<p>公告正文</p>",
    "published_at": "2026-05-29 10:00:00",
    "start_at": null,
    "end_at": null,
    "is_top": true,
    "status": 1,
    "sort": 0,
    "extra": [],
    "created_at": "2026-05-29 10:00:00",
    "updated_at": "2026-05-29 10:00:00"
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 规则

- 详情仅返回满足以下条件的数据：
  - `enabled()`
  - `forCity(city_code)`
  - `id = {id}`
- 不存在或不满足条件返回 `404`。
