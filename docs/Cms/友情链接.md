# 友情链接

## 1) 友情链接列表

- 接口: `GET /cms/friend-links`
- 路由名称: `friend-links`

### 请求示例

```http
GET /cms/friend-links
Authorization: Bearer {rc_access_token}
```

### 返回示例

```json
{
  "code": 200,
  "data": {
      "friend_links": [
          {
              "id": 88,
              "name": "示例友情链接",
              "url": "https://example.com",
              "logo": "https://cdn.example.com/friend-links/logo.png",
              "target": 1
          }
      ]
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 返回说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | integer | 业务状态码；`200` 表示请求成功 |
| `data.friend_links` | array | 友情链接列表 |
| `meta.timestamp` | number | 响应生成时间戳 |
| `meta.response_time` | number | 接口响应耗时，单位秒 |

### `friend_links[]` 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 友情链接 ID |
| `name` | string | 友情链接名称 |
| `url` | string | 友情链接跳转地址 |
| `logo` | string\|null | 友情链接 Logo URL；由 OSS 文件路径转换为可访问地址 |
| `target` | integer | 打开方式：`1` 当前页、`2` 新窗口 |

### 规则

- 查询条件：按请求解析出的 `city_code` 匹配城市友链或全站友链，并且仅返回启用状态。
- 排序规则：按 `sort asc` 排序。
- 返回字段限制：该接口仅返回 `id`、`name`、`url`、`logo`、`target`。
