# 校园活动

面向门户端的校招活动公开接口，用于活动列表页与详情页。数据来源于 `rc_school_activities`，仅返回**已发布**活动。

> 招聘方报名、校招负责人管理等接口见 [校招活动.md](../Rc/校招活动.md)。

---

## 1) 活动列表（分页）

- 接口: `GET /cms/school-activities`
- 鉴权: 无
- Query 参数:
  - `province_code`（可选，string）：省份编码，取值见 `GET /cms/meta` 地区树
  - `city_code`（可选，string）：城市编码
  - `district_code`（可选，string）：区县编码
  - `keyword`（可选，string，最大 100 字）：标题/描述/主办方/关键词等全文检索（走 Scout）
  - `type`（可选，int）：活动类型，单选
  - `types`（可选，array|string）：活动类型列表。支持 `types[]=0&types[]=1` 或 `types=0,1`
  - `organizer_type`（可选，string）：主办方类型，单选
  - `organizer_types`（可选，array|string）：主办方类型列表。支持数组或逗号分隔
  - `is_hot`（可选，bool）：是否热门活动
  - `page`（可选，int），默认 `1`
  - `per_page`（可选，int），默认 `15`，范围 `1 ~ 50`

### 活动类型枚举（`type` / `types`）

| value | label |
|-------|-------|
| `0` | 招聘会 |
| `1` | 宣讲会 |
| `2` | 双选会 |

### 主办方类型枚举（`organizer_type` / `organizer_types`）

| value | label |
|-------|-------|
| `school` | 学校 |
| `company` | 企业 |
| `area` | 区域 |

### 请求示例

```http
GET /cms/school-activities?city_code=360100&type=2&page=1&per_page=15
GET /cms/school-activities?types=0,1&organizer_types=school,company
GET /cms/school-activities?keyword=春季双选&city_code=110100
GET /cms/school-activities?is_hot=1
```

- 查询条件: `published()` + `forRegion(region_code)`；`region_code` 由 `district_code` > `city_code` > `province_code` 决定
- 地区匹配规则与公告一致：活动未配置省/市/区视为全国可见；否则命中任一区域编码即可
- `types`、`organizer_types` 为 OR 关系
- 有 `keyword` 时走 Scout 搜索；无关键词时走数据库查询
- 排序: `is_hot desc -> sort desc -> start_time desc -> id desc`
- 列表默认不返回 `description`、`contact_*`、`files` 等详情字段
- 列表/详情会返回统计字段：`company_applications_count`、`jobs_count`、`activity_booths_count`
- 非法枚举值返回 `422`

## 2) 活动详情

- 接口: `GET /cms/school-activities/{id}`
- 鉴权: 无
- Path 参数:
  - `id`（必填，int）：活动 ID
- Query 参数:
  - `province_code` / `city_code` / `district_code`（可选）：地区过滤，规则同列表接口

- 详情会返回统计字段：`company_applications_count`、`jobs_count`、`activity_booths_count`
- 关联学校通过 `schools` 返回，单项包含 `display_name`、`display_logo`

## 3) 公开邀请页（无需认证）

用于活动邀请二维码/链接落地页。学校主办双选会邀请企业填写信息；企业主办宣讲会邀请目标院校提交联系人信息。

### 3.1 邀请页活动详情

- 接口：`GET /cms/school-activities/invite/{inviteCode}`
- 认证：否

#### 成功响应 `data`

| 字段 | 说明 |
|------|------|
| `inviter_name` | 邀请方名称 |
| `invitation_message` | 邀请文案 |
| `invite_target` | `company` \| `school` |
| `activity` | 活动详情（含 `invite_code`） |

---

### 3.2 提交企业信息并加入活动

- 接口：`POST /cms/school-activities/invite/{inviteCode}/companies`
- 认证：否
- 适用：学校主办活动

#### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `name` | 是 | `string`, `max:255` | 企业名称 |
| `credit_code` | 是 | `string`, `size:18` | 统一社会信用代码 |
| `contact_phone` | 是 | `string`, `max:255` | 联系电话 |

#### 成功响应 `data`

| 字段 | 说明 |
|------|------|
| `company` | 新建或已存在的企业 |
| `application` | 活动企业关联记录 |

---

### 3.3 提交院校联系人信息并加入活动

- 接口：`POST /cms/school-activities/invite/{inviteCode}/schools`
- 认证：否
- 适用：企业主办活动（宣讲会须在创建时的目标院校名单内；招聘会未预选院校时首次提交会自动创建关联）

#### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `school_code` | 是 | `exists:schools,school_code` | 院校代码 |
| `contact_name` | 是 | `string`, `max:50` | 联系人姓名 |
| `contact_phone` | 是 | `string`, `max:20` | 联系电话 |
| `contact_email` | 否 | `email`, `max:100` | 联系邮箱 |
| `remark` | 否 | `string`, `max:2000` | 备注 |

#### 成功响应 `data`

| 字段 | 说明 |
|------|------|
| `school_application` | 活动院校关联记录（`apply_status=0` 待审核） |

## 4) 当前活动的审批通过企业列表

- 接口：`GET /cms/school-activities/{id}/companies`
- 鉴权：无
- Path 参数：
  - `id`（必填，int）：活动 ID
- Query 参数：
  - `scale_type`（可选，int）：公司规模，取值见 `CompanyScaleType`
  - `nature_type`（可选，int）：公司性质，取值见 `CompanyNatureType`
  - `per_page`（可选，int），默认 `15`，范围 `1 ~ 50`

### 公司规模枚举（`scale_type`）

| value | label |
|-------|-------|
| `1` | 0-20人 |
| `2` | 20-99人 |
| `3` | 100-499人 |
| `4` | 500-999人 |
| `5` | 1000-9999人 |
| `6` | 10000人以上 |

### 公司性质枚举（`nature_type`）

| value | label |
|-------|-------|
| `1` | 民营企业 |
| `2` | 国有企业 |
| `3` | 外资企业 |
| `4` | 合资企业 |
| `5` | 事业单位 |
| `6` | 非营利组织 |
| `7` | 其他 |

### 返回示例

```json
{
  "code": 200,
  "data": {
    "current_page": 1,
    "data": [
      {
        "id": 88,
        "activity_id": 12,
        "company_id": 31,
        "activity_jobs_count": 2,
        "company": {
          "id": 31,
          "name": "示例科技有限公司",
          "profile": {
            "short_name": "示例科技",
            "scale_type": 3,
            "scale_type_label": "100-499人",
            "nature_type": 1,
            "nature_type_label": "民营企业",
            "display_logo": "https://cdn.example.com/uploads/company.png"
          }
        },
        "activity_jobs": [
          {
            "id": 101,
            "job_id": 501,
            "audit_status": 1,
            "audit_status_label": "审核通过",
            "job": {
              "id": 501,
              "title": "Java 开发工程师",
              "company": {
                "id": 31,
                "profile": {
                  "short_name": "示例科技"
                }
              }
            }
          }
        ]
      }
    ],
    "per_page": 15,
    "total": 8
  }
}
```

### 规则

- 仅返回 `apply_status = approved` 的企业报名记录
- 仅返回该活动下 `audit_status = approved` 的职位
- 公司筛选作用于企业 profile 的 `scale_type` / `nature_type`
- 接口按企业报名时间倒序分页

## 5) 与首页推荐的关系

- 首页推荐: `GET /cms/home/schools`（各类型推荐 5 条，见 [首页.md](./首页.md)）
- 活动列表页: 使用本接口 `GET /cms/school-activities` 做分页与筛选
- 活动详情页: 使用本接口 `GET /cms/school-activities/{id}`

---

## 6) 前端使用建议

- 地区筛选器选项从 `GET /cms/meta` 加载
- 类型 / 主办方类型筛选项可使用上文枚举，或后续从 meta 字典扩展
- 列表卡片点击跳转详情时，建议携带当前选中的 `city_code` 以保持地区一致性
