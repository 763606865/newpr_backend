# 推荐位

门户首页推荐位列表接口，支持按城市、模块类型筛选，并返回分页结果。

---

## 1) 推荐位列表（分页）

- 接口: `GET /cms/home/recommendations`
- 路由名称: `home.recommendations`
- 鉴权: 无
- Query 参数:
  - `city_code`（可选，string）：城市编码
  - `module_type`（可选，int）：推荐模块类型
  - `per_page`（可选，int）：每页数量，默认 `15`，范围 `1 ~ 50`

### 推荐模块类型（`module_type`）

| value | label | 关联对象 |
|-------|-------|----------|
| `1` | 紧急招聘 | 职位（`job`） |
| `2` | 热招职位 | 职位（`job`） |
| `3` | 名企招聘 | 企业（`company`） |
| `4` | 校招-热门公司 | 企业（`company`） |
| `5` | 热门校招 | 职位（`job`） |

### 请求示例

```http
GET /cms/home/recommendations
GET /cms/home/recommendations?city_code=360100
GET /cms/home/recommendations?city_code=360100&module_type=5&per_page=10
```

### 规则

- 数据来源：`cms_home_recommendations`
- 查询条件：
  - `enabled()` + `active()` + `forCity(city_code)`
  - 传 `module_type` 时追加 `forModule(module_type)`
- 可见性过滤（仅返回可展示数据）：
  - 职位推荐：职位状态必须为「已发布」，且 `expired_at` 为空或未过期
  - 企业推荐：企业状态必须为「已启用」
- 关联加载：
  - 职位：`Job::discoveryRelations()`
  - 企业：`profile`、`albums`
- 排序：`sort asc, id desc`
- 返回：Laravel 分页结构，`data.data` 元素为 `CmsHomeRecommendationResource` 结构

### 校验失败

- `module_type` 非法时返回 `422`
- `per_page` 超出范围时返回 `422`
