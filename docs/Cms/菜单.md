# 菜单

## 1) 菜单列表

- 接口: `GET /cms/menus`
- 路由名称: `menus`
- 鉴权: 可选 RC 登录（见「公共说明」）

### 请求示例

```http
GET /cms/menus
Authorization: Bearer {rc_access_token}
```

### 返回说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | integer | 业务状态码；`200` 表示请求成功 |
| `data.menus` | array | 菜单树列表；顶级菜单在第一层，子菜单放在父级菜单的 `children` 中 |
| `meta.timestamp` | number | 响应生成时间戳 |
| `meta.response_time` | number | 接口响应耗时，单位秒 |

### `menus[]` 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 菜单 ID |
| `parent_id` | integer | 父级菜单 ID；`0` 表示顶级菜单 |
| `name` | string | 菜单名称 |
| `code` | string\|null | 菜单编码；通常用于与前端路由或后端路由名称关联 |
| `link_type` | integer | 链接类型：`1` 站内、`2` 站外、`3` 无跳转 |
| `link_url` | string\|null | 跳转地址；无跳转或未配置时为 `null` |
| `icon` | string\|null | 菜单图标标识或地址 |
| `image` | string\|null | 菜单图片 URL；由 OSS 文件路径转换为可访问地址 |
| `target` | integer | 打开方式：`1` 当前页、`2` 新窗口 |
| `is_show` | boolean | 是否前台展示；该接口只返回展示中的菜单 |
| `status` | integer | 状态：`1` 启用、`0` 停用；该接口只返回启用菜单 |
| `sort` | integer | 排序值，值越小越靠前 |
| `start_at` | string\|null | 生效开始时间 |
| `end_at` | string\|null | 生效结束时间 |
| `extra` | object\|array\|null | 扩展字段，结构由后台配置决定 |
| `children` | array | 子菜单列表；没有子菜单时为空数组 |

### 规则

- 鉴权为可选；未携带或 Token 无效时按游客身份过滤菜单。
- 查询条件：仅返回启用、前台展示、且当前身份可见的菜单。
- 排序规则：按 `sort asc, id asc` 排序后组装为树形结构。

### 返回示例

```json
{
  "code": 200,
  "data": {
      "menus": [
          {
              "id": 1,
              "parent_id": 0,
              "name": "首页",
              "code": "home",
              "link_type": 1,
              "link_url": "/",
              "icon": null,
              "image": null,
              "target": 1,
              "is_show": true,
              "status": 1,
              "sort": 0,
              "start_at": null,
              "end_at": null,
              "extra": [],
              "children": []
          }
      ]
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```
