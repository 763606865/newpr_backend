# 站点配置

## 1) 站点配置列表

- 接口: `GET /cms/site-configs`
- 路由名称: `site-configs`

### 请求示例

```http
GET /cms/site-configs
Authorization: Bearer {rc_access_token}
```

### 返回说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | integer | 业务状态码；`200` 表示请求成功 |
| `data` | object\|null | 当前站点配置；无匹配的启用配置时为 `null` |
| `meta.timestamp` | number | 响应生成时间戳 |
| `meta.response_time` | number | 接口响应耗时，单位秒 |

### `data` 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 站点配置 ID |
| `site_code` | string | 站点编码 |
| `city_code` | string\|null | 城市编码；为空表示全站默认站点 |
| `name` | string | 站点名称 |
| `short_name` | string\|null | 站点简称 |
| `domain` | string\|null | 站点域名 |
| `logo` | string\|null | 站点 Logo URL；由 OSS 文件路径转换为可访问地址 |
| `favicon` | string\|null | 站点图标 URL；由 OSS 文件路径转换为可访问地址 |
| `slogan` | string\|null | 站点 Slogan |
| `icp_no` | string\|null | ICP 备案号 |
| `public_security_no` | string\|null | 公安备案号 |
| `service_phone` | string\|null | 客服电话 |
| `service_email` | string\|null | 客服邮箱 |
| `seo_title` | string\|null | SEO 标题 |
| `seo_keywords` | string\|null | SEO 关键词 |
| `seo_description` | string\|null | SEO 描述 |
| `status` | integer | 状态：`1` 启用、`0` 停用；该接口只返回启用配置 |
| `theme_config` | object\|array\|null | 主题配置，结构由后台配置决定 |
| `extra` | object\|array\|null | 扩展配置，结构由后台配置决定 |
| `created_at` | string\|null | 创建时间，格式为 `YYYY-MM-DD HH:mm:ss` |
| `updated_at` | string\|null | 更新时间，格式为 `YYYY-MM-DD HH:mm:ss` |

### 规则

- 查询条件：按请求解析出的 `city_code` 匹配城市配置或全站默认配置，并且仅返回启用状态。
- 返回数量：取第一条匹配的站点配置；不存在时 `data` 为 `null`。
