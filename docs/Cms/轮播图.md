# 轮播图

门户端 Banner 读取接口，支持按 Banner 版位编码和城市编码获取可展示的轮播图。

---

## 1) Banner 列表

- 接口: `GET /cms/home/banners`
- 路由名称: `home.banners`
- 鉴权: 无
- Query 参数:
  - `banner_position_code`（必填，string）：Banner 版位编码
  - `city_code`（可选，string）：城市编码，取值见 `GET /cms/meta` 地区树中**市级**节点 `code`

### 请求示例

```http
GET /cms/home/banners?banner_position_code=zcgz.index.banner-1
GET /cms/home/banners?banner_position_code=zcgz.index.banner-1&city_code=360100
```

### 规则

- 先按 `banner_position_code` 定位版位，版位必须为启用状态
- `banners` 关联查询：
  - `enabled()`
  - `forCity(city_code)`；传入城市时，返回该城市或全国通用（`city_code = null`）的 Banner
  - 排序：`sort asc -> id asc`
- 找不到版位时返回 `404`
- 返回的 Banner 资源包含 `image_url`，可直接用于前端展示
