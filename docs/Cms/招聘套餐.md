# 招聘套餐

## 1) 招聘套餐列表

- 接口：`GET /cms/rc/biz-plans`
- 路由名称：`rc.biz-plan.index`
- 请求参数：无
- 鉴权：可选，支持游客访问，也支持 RC Bearer Token
- 描述：根据当前访问者身份返回可购买的 RC 招聘业务商品套餐

### 身份与套餐范围

| 当前访问身份 | 返回套餐 |
|-------------|----------|
| 游客 | 求职者套餐 |
| 求职者 | 求职者套餐 |
| 招聘方 | 招聘方套餐 |
| 登录但没有有效身份 | 求职者套餐 |
| 其他身份 | 求职者套餐 |

身份判断复用 CMS 当前身份解析规则：

1. 优先使用当前切换的 RC 身份；
2. 未切换身份时，优先使用默认身份；
3. 默认身份不存在时，使用第一个启用身份；
4. 仅当最终身份为招聘方时返回招聘方套餐，其余情况均返回求职者套餐。

### 请求示例

游客或求职者：

```http
GET /cms/rc/biz-plans
```

已登录用户：

```http
GET /cms/rc/biz-plans
Authorization: Bearer {rc_access_token}
```

### 返回字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 套餐 ID |
| `plan_name` | string | 套餐名称 |
| `plan_code` | string | 套餐唯一编码 |
| `price` | string | 套餐价格，保留两位小数 |
| `duration` | integer | 套餐有效时长，单位为天；`0` 表示永久 |
| `target_side` | integer | 目标用户端 |
| `target_side_label` | string | 目标用户端名称 |
| `product_type` | integer | 商品类型 |
| `product_type_label` | string | 商品类型名称 |
| `billing_cycle` | integer | 计费周期 |
| `billing_cycle_label` | string | 计费周期名称 |
| `remark` | string\|null | 套餐描述 |
| `quota_rules` | object\|array\|null | 套餐包含的权益及配额规则 |
| `extra` | object\|array\|null | 扩展属性 |

### 目标用户端枚举

| value | label | 说明 |
|-------|-------|------|
| `1` | B端招聘方 | 招聘企业可购买的套餐 |
| `2` | C端求职者 | 求职者可购买的套餐 |

### 商品类型枚举

| value | label |
|-------|-------|
| `1` | 职位发布 |
| `2` | 会员套餐 |
| `3` | 增值道具 |
| `4` | AI工具 |
| `5` | 简历优化 |
| `6` | VIP辅导 |
| `7` | 简历刷新 |
| `8` | 简历曝光 |

### 计费周期枚举

| value | label |
|-------|-------|

| `3` | 按季 |
| `4` | 按年 |
| `5` | 按量 |

### 查询规则

- 数据来源：`rc_biz_plans` 表，不包含 OA 业务的 `oa_biz_plans`。
- 仅返回启用状态的套餐，即 `status = 1`。
- 招聘方仅返回 `target_side = 1` 的套餐。
- 游客、求职者及其他身份返回 `target_side = 2` 的套餐。
- 排序规则：`sort asc`，相同排序值时按 `id asc`。
- 接口当前不分页。
- 接口当前不接收商品类型、价格或计费周期筛选参数。
- 请求携带无效或过期 Token 时，`optional-rc-auth` 会按游客继续访问，并返回求职者套餐。

## 2) 前端使用建议

- 游客页面可以直接请求接口，无需构造 Token。
- 登录后切换求职者或招聘方身份，应重新请求套餐列表。
- 价格展示应以接口返回的 `price` 为准，不建议前端自行写死。
- 套餐权益展示应读取 `quota_rules`，具体键名由运营后台配置。
- `plan_code` 适合用于前端埋点和套餐展示映射；创建订单时应以服务端要求的套餐 ID 或套餐编码为准。
