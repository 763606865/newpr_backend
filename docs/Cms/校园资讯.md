# 校园资讯

面向门户端的校园资讯公开接口，数据来源于 `cms_articles`，仅返回**已发布**资讯。

> 校招负责人在 RC 端的管理接口见 [校招资讯.md](../Rc/校招资讯.md)。

---

## 1) 资讯列表（分页）

- 接口: `GET /cms/articles`
- 鉴权: 无
- Query 参数:
  - `city_code`（可选，string）：城市编码，取值见 `GET /cms/meta` 地区树中**市级**节点 `code`
  - `school_code`（可选，string）：院校代码，筛选某院校发布的资讯
  - `category_id`（可选，int）：文章分类 ID
  - `category_slug`（可选，string）：文章分类别名，如 `campus-news`
  - `keyword`（可选，string，最大 100 字）：标题/摘要模糊搜索
  - `is_recommend`（可选，bool）：是否推荐资讯
  - `tag_ids`（可选，array|string）：文章标签 ID 列表。支持 `tag_ids[]=1&tag_ids[]=2` 或 `tag_ids=1,2`
  - `tags_match`（可选，string）：标签匹配方式，默认 `all`
    - `all`：须**同时包含**全部指定标签
    - `any`：包含**任一**指定标签即可
  - `page`（可选，int），默认 `1`
  - `per_page`（可选，int），默认 `15`，范围 `1 ~ 50`

### 请求示例

```http
GET /cms/articles?city_code=360100&category_slug=campus-news&page=1&per_page=15
GET /cms/articles?school_code=4111010001
GET /cms/articles?keyword=就业政策&is_recommend=1
GET /cms/articles?tag_ids=1,2&tags_match=any
```

### 规则

- 查询条件: `published()`（`status = 2`）
- 传入 `city_code` 时额外执行 `forCity()`：匹配该城市或全站（`city_code` 为空）资讯
- 排序: `is_top desc -> is_recommend desc -> published_at desc -> id desc`
- 列表不返回正文，详情见下方接口

## 2) 资讯详情

- 接口: `GET /cms/articles/{id}`
- 鉴权: 无
- Path 参数:
  - `id`（必填，int）：资讯 ID
- Query 参数:
  - `city_code`（可选，string）：城市编码，规则同列表接口

### 返回示例

```json
{
  "code": 200,
  "data": {
    "id": 10,
    "category_id": 3,
    "city_code": null,
    "school_code": "4111010001",
    "school_name": "北京大学",
    "title": "2026 就业政策解读",
    "sub_title": null,
    "slug": null,
    "cover": null,
    "display_cover": null,
    "summary": "摘要内容",
    "author": "就业办",
    "source_name": null,
    "is_top": false,
    "is_recommend": true,
    "published_at": "2026-06-23 10:00:00",
    "view_count": 13,
    "category": {
      "id": 3,
      "name": "校园资讯",
      "slug": "campus-news"
    },
    "source_url": null,
    "content": "<p>正文内容</p>",
    "content_type": 1,
    "content_type_label": "HTML",
```

### 规则

- 详情仅返回 `published()` 且满足 `forCity(city_code)` 的资讯
- 不存在或不满足条件返回 `404`
- 访问详情会自动 `view_count + 1`

---

## 3) 数据说明

| 字段 | 说明 |
|------|------|
| `school_code` | 为空表示平台资讯；有值表示某院校在 RC 端发布的资讯 |
| `school_name` | 由 `school_code` 关联 `schools` 表得到 |
| `category` | 来自 `cms_article_categories`，可在 Filament 后台维护 |
| `tags` | 来自 `cms_article_tags`，可在 Filament 后台维护 |

---

## 4) 前端使用建议

- 校园资讯栏目页：按 `category_slug=campus-news`（或具体子分类 slug）拉列表
- 院校专区：传 `school_code` 只看该院校资讯
- 分类、标签选项从 `GET /cms/meta/articles` 加载（或汇总接口 `GET /cms/meta`）
