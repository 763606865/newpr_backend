# 首页

## 1) 首页内容

- 鉴权: 无
- Query 参数:

### 说明

- `menus`: 树状结构，来自 `CmsMenuCollection`。
- `banner_position`: 查询 `code = zcgz.index.banner-1` 的已启用版位，包含 `banners`（已启用，按 `sort` 升序）。
- `ad_slot`: 查询 `code like '%index.%'` 的已启用广告位，包含 `ads`（已启用，按 `sort` 升序）。
- `site_config`: 当前站点配置，查询条件为 `forCity(city_code)` + `enabled()`，返回第一条匹配数据。
  - 主要字段包括站点名称、域名、Logo、Favicon、客服信息、SEO 信息、主题配置等。
  - `logo` / `favicon` 经过 OSS cast 序列化后，返回可直接访问的 URL。
- `friend_links`: 友情链接列表，查询条件为 `forCity(city_code)` + `enabled()` + `sort asc`。
  - 当前返回字段：`id`、`name`、`url`、`logo`、`target`。

## 2) 首页公告简介（最多 10 条）

- 接口: `GET /cms/home/announcements`
- 鉴权: 无
- Query 参数:
  - `city_code`（可选，string）

### 返回示例

```json
{
  "code": 200,
  "data": {
    "banner_position": {
      "id": 1,
      "name": "公告页 Banner 位",
      "code": "zcgz.announcement.banner-1",
      "width": 1200,
      "height": 360,
      "status": 1,
      "sort": 0,
      "remark": null,
      "created_at": "2026-05-29 10:00:00",
      "updated_at": "2026-05-29 10:00:00",
      "banners": []
    },
    "ad_slot": [
      {
        "id": 20,
        "name": "公告页广告位",
        "code": "index.announcement.top",
        "type": 1,
        "width": 375,
        "height": 120,
        "status": 1,
        "sort": 0,
        "remark": null,
        "created_at": "2026-05-29 10:00:00",
        "updated_at": "2026-05-29 10:00:00",
        "ads": []
      }
    ],
    "announcements": [
      {
        "id": 300,
        "city_code": null,
        "title": "系统公告标题",
        "sub_title": "系统公告副标题",
        "summary": "公告摘要",
        "link_url": null,
        "type": 1,
        "source_name": "官网",
        "published_at": "2026-05-29 10:00:00",
        "is_top": true
      }
    ]
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 规则

- `banner_position`: `enabled()` + `code = zcgz.announcement.banner-1`，并加载 `banners`（`enabled()` + `forCity(city_code)` + `sort asc`）
- `ad_slot`: `enabled()` + `whereLike('code', '%announcement.%')` + `sort asc`，并加载 `ads`（`enabled()` + `forCity(city_code)` + `sort asc`）
- `announcements`: `enabled()` + `forCity(city_code)`，按 `is_top desc -> sort asc -> published_at desc` 排序
- 数量: `limit(10)`

## 3) 首页岗位信息

- 接口: `GET /cms/home/rc/positions`
- 鉴权: 无
- Query 参数: 无

### 返回示例

```json
{
  "code": 200,
  "data": {
    "positions": [
      {
        "id": 1,
        "parent_id": null,
        "name": "技术",
        "code": "tech",
        "sort": 1,
        "extra": null,
        "children": [
          {
            "id": 2,
            "parent_id": 1,
            "name": "后端开发",
            "code": "backend-dev",
            "sort": 1,
            "extra": null,
            "children": []
          }
        ]
      }
    ]
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 规则

- 数据来源: `rc_positions`
- 查询排序: `sort asc, id asc`
- 序列化: 使用 `RcPositionResource`
- 返回结构: `data.positions` 为树状结构（通过 `tree()` 生成）
