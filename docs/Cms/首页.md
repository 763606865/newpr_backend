# 首页

面向门户端的首页聚合接口，用于加载导航菜单、Banner/广告、站点配置、首页推荐模块，以及公告/校园/元数据等子模块内容。

> 公告列表与详情见 [公告页.md](./公告页.md)；校园活动列表与详情见 [校园活动.md](./校园活动.md)；地区等元数据见 [Meta.md](./Meta.md)。

---

## 公共说明

- 路由前缀：`/cms`
- 返回格式：成功时使用 `api_response()`，结构为 `code` + `data` + `meta`
- 鉴权：**可选 RC 登录**
  - 未携带 Token，或 Token 无效时，按**游客**处理（不会返回 401）
  - 携带有效 RC Token 时（`Authorization: Bearer {access_token}`），按当前 RC 身份解析菜单可见性与路由访问权限
- 路由访问控制：上述首页相关接口均挂载 `cms-home-menu` 中间件
  - 以 Laravel 路由名称作为 CMS 菜单 `code` 进行匹配（如 `home`、`home.school`）
  - 若后台存在同名菜单且配置了可见身份，则当前身份不在允许范围内时返回 **403**
  - 403 响应示例：`{"message":"当前身份无权访问该内容。"}`
- `city_code`（可选，string）：城市编码，取值见 `GET /cms/meta` 地区树中**市级**节点 `code`
  - 传入时，多数「按城市筛选」逻辑为：`city_code = 指定值 OR city_code IS NULL`（即同时返回全国通用配置）
  - 不传或传空字符串时，不做城市过滤

### CMS 菜单可见身份（`CmsMenuAudienceType`）

| value | label |
|-------|-------|
| `0` | 游客 |
| `1` | 求职者 |
| `2` | 招聘方 |
| `3` | 校招负责人 |
| `4` | 政府机构负责人 |
| `5` | 猎头 |

- 菜单未配置 `menu_identities` 时，对所有身份可见
- 菜单已配置 `menu_identities` 时，仅对匹配身份可见

### 首页推荐模块类型（`module_type`）

| value | label | 关联对象 |
|-------|-------|----------|
| `1` | 紧急招聘 | 职位（`job`） |
| `2` | 热招职位 | 职位（`job`） |
| `3` | 名企招聘 | 企业（`company`） |

### 字段说明

| 字段 | 说明 |
|------|------|
| `menus` | 导航菜单树，序列化自 `CmsMenuCollection` |
| `banner_position` | 首页 Banner 版位；无匹配数据时为 `null` |
| `ad_slot` | 首页广告位列表 |

| `friend_links` | 友情链接列表 |
| `urgent_jobs` | 紧急招聘推荐列表 |
| `hot_jobs` | 热招职位推荐列表 |
| `famous_companies` | 名企招聘推荐列表 |

### 规则

- `menus`
  - 查询：`enabled()` + `shown()` + `forIdentity(当前 RC 身份)`
  - 未登录时按游客身份过滤；已登录时按当前 RC 身份类型过滤
  - 排序：`sort asc, id asc`，再通过 `tree()` 组装为树
- `banner_position`
  - 查询：`enabled()` + `code = zcgz.index.banner-1`
  - 关联 `banners`：`enabled()` + `sort asc`（**不按 `city_code` 过滤**）
- `ad_slot`
  - 查询：`enabled()` + `code like '%index.%'` + `sort asc`
  - 关联 `ads`：`enabled()` + `sort asc`（**不按 `city_code` 过滤**）
- `site_config`
  - 查询：`forCity(city_code)` + `enabled()`，取第一条
  - `logo` / `favicon` 经 OSS cast 序列化，返回可直接访问的 URL
- `friend_links`
  - 查询：`forCity(city_code)` + `enabled()` + `sort asc`
  - 返回字段：`id`、`name`、`url`、`logo`、`target`
- `urgent_jobs` / `hot_jobs` / `famous_companies`
  - 数据来源：`cms_home_recommendations`
  - 查询：`enabled()` + `active()` + `forCity(city_code)` + `forModule(模块类型)` + `sort asc, id desc`
  - 序列化：`CmsHomeRecommendationResource`
  - 展示过滤（后端二次过滤，不满足则不返回）：
    - 职位模块：职位状态须为「已发布」，且未过期（`expired_at` 为空或未到期）
    - 名企模块：企业状态须为「已启用」
  - 职位模块额外返回嵌套 `job`（`RcJobResource`，含 `company`、`position` 等关联）
  - 名企模块额外返回嵌套 `company`（`RcCompanyDiscoveryResource`）
  - `title` 优先取推荐配置标题；为空时职位取 `job.title`，名企取 `profile.short_name` 或 `company.name`

- 活动列表页与详情页分别使用 `GET /cms/school-activities`、`GET /cms/school-activities/{id}`，详见 [校园活动.md](./校园活动.md)

## 6) 前端使用建议

- 地区切换：城市选项从 `GET /cms/meta` 加载，切换后带上 `city_code` 重新请求首页相关接口
- 导航菜单：`menus` 已按当前身份过滤，前端可直接渲染；如需与路由权限联动，需与后台菜单 `code`（路由名称）保持一致
- 登录态：携带 RC Token 时可获得身份专属菜单；Token 失效时不阻断访问，按游客降级
- 子模块按需加载：首页主体用 `GET /cms/home`；公告区块、校园区块、岗位/行业筛选器可分别调用对应子接口，减少首屏 payload
- 403 处理：若某首页子模块返回 403，建议隐藏对应入口或展示「当前身份不可见」提示，而非整页报错
