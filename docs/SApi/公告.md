# SApi 公告

## 说明

- 路由前缀：`/sapi`
- 鉴权：[加签鉴权](./鉴权.md)
- 用途：对接方拉取已发布公告，支持按创建时间增量同步
- 成功响应：`code` + `data` + `meta`（`data` 为 Laravel 分页结构）

---

## 1) 公告列表

- 接口：`GET /sapi/announcements`
- 描述：分页拉取**已发布**公告，可按城市、创建时间筛选

### Query 参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `city_code` | 否 | `string`, `max:32` | 城市编码；返回该城市及全站（`city_code` 为空）公告 |
| `created_from` | 否 | `date_format:Y-m-d H:i:s` | 创建时间起始（含） |
| `created_to` | 否 | `date_format:Y-m-d H:i:s` | 创建时间截止（含），须 `>= created_from` |
| `page` | 否 | `integer`, `min:1` | 页码，默认 `1` |
| `per_page` | 否 | `integer`, `1~100` | 每页条数，默认 `15` |

### 请求示例

```http
GET /sapi/announcements?created_from=2026-06-01%2000:00:00&created_to=2026-06-03%2023:59:59&per_page=50 HTTP/1.1
X-SApi-App-Key: sapi_xxxxxxxx
X-SApi-Timestamp: 1717488000
X-SApi-Nonce: abc123
X-SApi-Sign: <signature>
```

> Query 参与签名，须与签名时编码一致（见 [鉴权.md](./鉴权.md)）。

### 查询规则

- 仅返回 `status = 2`（已发布）的公告
- `city_code`：匹配指定城市 **或** `city_code IS NULL`（全站公告）
- `created_from` / `created_to`：按 `created_at` 闭区间筛选，可只传其一
- 排序：`id DESC`

### 列表项字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 公告 ID |
| `city_code` | string\|null | 城市编码，`null` 表示全站 |
| `title` | string | 标题 |
| `sub_title` | string\|null | 副标题 |
| `link_url` | string\|null | 外链 |
| `type` | int | `1` 自发 / `2` 采集 / `3` 授权 |
| `source_name` | string\|null | 来源名称 |
| `source_url` | string\|null | 来源地址 |
| `summary` | string\|null | 摘要 |
| `content` | string\|null | 正文 |
| `published_at` | string\|null | 发布时间 |
| `start_at` | string\|null | 生效开始 |
| `end_at` | string\|null | 生效结束 |
| `is_top` | bool | 是否置顶 |
| `status` | int | 固定为 `2`（已发布） |
| `sort` | int | 排序值 |
| `extra` | object\|null | 扩展字段 |
| `created_at` | string | 创建时间 |
| `updated_at` | string | 更新时间 |

### 校验失败示例

```json
{
  "message": "The 创建时间起始 field must match the format Y-m-d H:i:s.",
  "errors": {
    "created_from": ["The 创建时间起始 field must match the format Y-m-d H:i:s."]
  }
}
```

HTTP `422`。

### 增量同步建议

1. 首次全量：不传时间，分页拉取直至 `current_page >= last_page`
2. 增量：记录上次同步最大 `created_at`，下次请求 `created_from=上次时间`
3. 建议 `per_page=50~100` 以减少请求次数
