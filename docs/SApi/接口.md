# SApi 接口

## 说明

- 路由前缀：`/sapi`
- 鉴权：均需 [加签鉴权](./鉴权.md)，无 Bearer Token
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 鉴权/业务错误：JSON 结构为 `code` + `message` + `meta`

---

## 1) 健康检查

- 接口：`GET /sapi/ping`
- 描述：验证加签鉴权是否配置正确，并返回当前接入客户端信息
- 鉴权：是（加签）

### 请求参数

无 Query、无 Body。

### 请求示例

```http
GET /sapi/ping HTTP/1.1
Host: example.com
X-SApi-App-Key: sapi_xxxxxxxxxxxxxxxx
X-SApi-Timestamp: 1717488000
X-SApi-Nonce: 8f3a2b1c9d0e4f5a
X-SApi-Sign: <按鉴权文档计算的签名>
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "message": "pong",
    "client": {
      "id": 1,
      "name": "示例对接方",
      "app_key": "sapi_xxxxxxxxxxxxxxxx"
    }
  },
  "meta": {
    "timestamp": 1748865600.1234,
    "response_time": 0.0123
  }
}
```

### 响应字段（`data`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `message` | string | 固定为 `pong` |
| `client` | object | 当前鉴权通过的接入客户端摘要 |
| `client.id` | int | 客户端 ID |
| `client.name` | string | 客户端名称 |
| `client.app_key` | string | 应用 Key |

> 响应中**不返回** `app_secret`。

### 失败响应

鉴权失败见 [鉴权.md](./鉴权.md#鉴权失败响应)，HTTP `401`。

---

## 2) 公告列表

- 接口：`GET /sapi/announcements`
- 描述：分页拉取已发布公告，支持 `created_from` / `created_to` 创建时间筛选
- 详细说明见 [公告.md](./公告.md)
