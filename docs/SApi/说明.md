# SApi 说明

## 概述

SApi（Service API）面向**服务端对接**场景，供内部系统、合作方或自动化服务以加签方式调用本平台接口。与面向终端用户的 `api` / `rc` / `b`（Passport Bearer Token）鉴权体系相互独立。

## 约定

| 项目 | 说明 |
|------|------|
| 路由前缀 | `/sapi` |
| 鉴权方式 | HMAC-SHA256 加签（见 [鉴权.md](./鉴权.md)） |
| 成功响应 | `api_response()`：`code` + `data` + `meta` |
| 业务/鉴权错误 | JSON：`code` + `message` + `meta` |
| HTTP 状态码 | 成功一般为 `200`；鉴权失败为 `401` |

## 环境配置

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `SAPI_TIMESTAMP_TOLERANCE` | `300` | 时间戳允许偏差（秒） |
| `SAPI_NONCE_CACHE_STORE` | 空（使用默认缓存） | Nonce 防重放缓存驱动，生产建议 `redis` |

配置文件：`config/sapi.php`。

## 接入客户端

平台为每个对接方分配一对凭证，存储于表 `sapi_clients`：

| 字段 | 说明 |
|------|------|
| `app_key` | 应用 Key，参与签名并用于识别客户端 |
| `app_secret` | 应用 Secret，仅用于本地计算签名，**不得外传** |
| `status` | `1` 启用 / `0` 停用 |
| `allowed_ips` | IP 白名单 JSON 数组；`null` 或空数组表示不限制 |

凭证由运营/后台创建后线下交付对接方。推荐使用 Artisan 命令创建（**App Secret 仅在创建时输出一次**）：

```bash
php artisan sapi:client:create "对接方名称"

# 可选参数
php artisan sapi:client:create "对接方名称" --remark="备注" --ip=203.0.113.1 --ip=203.0.113.2
php artisan sapi:client:create "对接方名称" --disabled
```

## 快速验证

在取得 `app_key`、`app_secret` 后，可按 [鉴权.md](./鉴权.md) 计算签名并请求：

```http
GET /sapi/ping
X-SApi-App-Key: <app_key>
X-SApi-Timestamp: <unix_timestamp>
X-SApi-Nonce: <random_string>
X-SApi-Sign: <signature>
```

成功时 `data.message` 为 `pong`，并返回当前客户端信息。
