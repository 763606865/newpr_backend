# SApi 业务数据

## 说明

- 路由前缀：`/sapi`
- 鉴权：[加签鉴权](./鉴权.md)
- 用途：对接方分页拉取职位、简历、企业、用户等业务数据，支持按创建/更新时间增量同步
- 成功响应：`code` + `data` + `meta`（`data` 为 Laravel 分页结构）
- 默认排序：各列表均按 `id DESC`
- 软删除记录默认不返回

## 通用 Query 参数

以下参数在四个列表接口中通用（除各接口专有筛选外）：

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| created_from | 否 | date_format:Y-m-d H:i:s | 创建时间起始（含） |
| created_to | 否 | date_format:Y-m-d H:i:s | 创建时间截止（含），须大于等于 created_from |
| updated_from | 否 | date_format:Y-m-d H:i:s | 更新时间起始（含） |
| updated_to | 否 | date_format:Y-m-d H:i:s | 更新时间截止（含），须大于等于 updated_from |
| page | 否 | integer, min:1 | 页码，默认 1 |
| per_page | 否 | integer, 1~100 | 每页条数，默认 15 |

### 增量同步建议

1. 首次全量：不传时间条件，分页拉取直至 current_page 大于等于 last_page
2. 按创建时间增量：记录上次同步最大 created_at，下次传 created_from=上次时间
3. 按更新时间增量（推荐）：记录上次同步最大 updated_at，下次传 updated_from=上次时间
4. 建议 per_page 取 50~100，以减少请求次数

## 1) 职位列表

- 接口：GET /sapi/jobs
- 描述：分页拉取招聘职位（含各状态，不含已软删除）

### 专有 Query 参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| company_id | 否 | integer, min:1 | 企业 ID |
| city_code | 否 | string, max:32 | 工作城市编码 |
| status | 否 | integer, in:0,1,2,3,4 | 0 草稿 / 1 已发布 / 2 暂停 / 3 关闭 / 4 过期 |

### 请求示例

```http
GET /sapi/jobs?company_id=1&status=1&updated_from=2026-06-01%2000:00:00&per_page=50 HTTP/1.1
X-SApi-App-Key: sapi_xxxxxxxx
X-SApi-Timestamp: 1717488000
X-SApi-Nonce: abc123
X-SApi-Sign: 计算后的签名值
```

### 列表项字段（data.data 数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 职位 ID |
| company_id | int | 企业 ID |
| department_id | int，可空 | 部门 ID |
| position_code | string，可空 | 岗位编码 |
| creator_user_id | int，可空 | 创建人用户 ID |
| code | string | 职位编码 |
| title | string | 职位名称 |
| employment_type | int | 用工类型 |
| city_code | string，可空 | 工作城市编码 |
| workplace | string，可空 | 工作地点 |
| salary_min | string，可空 | 最低薪资 |
| salary_max | string，可空 | 最高薪资 |
| salary_unit | int | 薪资单位 |
| experience_min | int，可空 | 最低经验年限 |
| experience_max | int，可空 | 最高经验年限 |
| education_level | int，可空 | 最低学历要求 |
| education_level_label | string，可空 | 学历标签 |
| headcount | int | 招聘人数 |
| description | string，可空 | 职位描述 |
| requirement | string，可空 | 职位要求 |
| benefit | string，可空 | 福利待遇 |
| status | int | 职位状态 |
| published_at | string，可空 | 发布时间 |
| expired_at | string，可空 | 过期时间 |
| keywords | array | 关键词 |
| extra | object，可空 | 扩展字段 |
| company | object，可空 | 含 id、name |
| position | object，可空 | 含 code、name |
| created_at | string | 创建时间 |
| updated_at | string | 更新时间 |

## 4) 用户列表

- 接口：GET /sapi/users
- 描述：分页拉取平台用户（不含已软删除，不返回 password 字段）

### 专有 Query 参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| status | 否 | string, max:32 | 用户状态，如 active |

### 请求示例

```http
GET /sapi/users?status=active&per_page=100 HTTP/1.1
X-SApi-App-Key: sapi_xxxxxxxx
X-SApi-Timestamp: 1717488000
X-SApi-Nonce: abc123
X-SApi-Sign: 计算后的签名值
```

### 列表项字段（data.data 数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 用户 ID |
| uuid | string，可空 | 全局唯一用户标识 |
| name | string，可空 | 真实姓名 |
| nickname | string，可空 | 昵称 |
| phone | string，可空 | 手机号 |
| email | string，可空 | 邮箱 |
| hub_user_id | string，可空 | 枢纽用户 ID |
| gender | int | 性别枚举 |
| avatar | string，可空 | 头像 |
| status | string | 用户状态 |
| last_login_ip | string，可空 | 最后登录 IP |
| last_login_at | string，可空 | 最后登录时间 |
| extra | object，可空 | 扩展字段 |
| created_at | string | 创建时间 |
| updated_at | string | 更新时间 |

## 成功响应结构（通用）

```json
{
  "code": 200,
  "data": {
    "current_page": 1,
    "data": [],
    "per_page": 15,
    "total": 0
  },
  "meta": {
    "timestamp": 1748865600.1234,
    "response_time": 0.0123
  }
}
```

### 校验失败

参数格式错误时 HTTP 状态码 422，结构与 Laravel 默认校验响应一致。
