# SApi 业务数据

## 说明

- 路由前缀：`/sapi`
- 鉴权：[加签鉴权](./鉴权.md)
- 用途：对接方拉取职位、简历、企业、用户等业务数据，支持按创建/更新时间增量同步
- 成功响应：`code` + `data` + `meta`
- 默认排序：各列表均按 `id DESC`
- 软删除记录默认不返回
- 公告列表见 [公告.md](./公告.md)，分页规则与本页一致

## 分页配置

服务端通过环境变量控制默认分页行为：

| 配置项 | 环境变量 | 默认值 | 说明 |
|--------|----------|--------|------|
| 是否开启分页 | `SAPI_PAGINATION_ENABLED` | `true` | `true` 时分页返回；`false` 时全量返回 |

**单次请求覆盖（优先级高于环境变量）：**

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| pagination_enabled | 否 | boolean | `1`/`0`、`true`/`false` 等；传 `0` 强制全量，传 `1` 强制分页 |

> `pagination_enabled` 参与 Query 签名校验，加签时须与实际请求参数一致。

### 响应结构差异

**分页模式**（`SAPI_PAGINATION_ENABLED=true` 且未传 `pagination_enabled=0`）：

- `data` 为 Laravel 分页对象，`data.data` 为列表数组
- 含 `total`、`per_page`、`current_page`、`last_page` 等字段

**全量模式**（`SAPI_PAGINATION_ENABLED=false` 或传 `pagination_enabled=0`）：

- `data` 直接为业务对象数组
- 不含 `total`、`current_page` 等分页字段

## 通用 Query 参数

以下参数在 jobs / resumes / companies / users 四个列表接口中通用（除各接口专有筛选外）：

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| created_from | 否 | date_format:Y-m-d H:i:s | 创建时间起始（含） |
| created_to | 否 | date_format:Y-m-d H:i:s | 创建时间截止（含），须大于等于 created_from |
| updated_from | 否 | date_format:Y-m-d H:i:s | 更新时间起始（含） |
| updated_to | 否 | date_format:Y-m-d H:i:s | 更新时间截止（含），须大于等于 updated_from |
| pagination_enabled | 否 | boolean | 单次覆盖是否分页，见上文 |
| page | 否 | integer, min:1 | 页码，默认 1（仅分页模式有效） |
| per_page | 否 | integer, 1~100 | 每页条数，默认 15（仅分页模式有效） |

### 增量同步建议

**分页模式：**

1. 首次全量：不传时间条件，分页拉取直至 `current_page >= last_page`
2. 按创建时间增量：记录上次同步最大 `created_at`，下次传 `created_from=上次时间`
3. 按更新时间增量（推荐）：记录上次同步最大 `updated_at`，下次传 `updated_from=上次时间`
4. 建议 `per_page` 取 50~100，以减少请求次数

**全量模式：**

1. 适合数据量较小或初始化同步
2. 可传 `pagination_enabled=0` 临时全量，无需修改服务端配置
3. 仍建议配合 `updated_from` 做增量筛选，避免单次返回过大

## 1) 职位列表

- 接口：GET /sapi/jobs
- 描述：拉取招聘职位（含各状态，不含已软删除）

### 专有 Query 参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| company_id | 否 | integer, min:1 | 企业 ID |
| city_code | 否 | string, max:32 | 工作城市编码 |
| status | 否 | integer, in:0,1,2,3,4 | 0 草稿 / 1 已发布 / 2 暂停 / 3 关闭 / 4 过期 |

### 请求示例（分页）

```http
GET /sapi/jobs?company_id=1&status=1&updated_from=2026-06-01%2000:00:00&per_page=50 HTTP/1.1
X-SApi-App-Key: sapi_xxxxxxxx
X-SApi-Timestamp: 1717488000
X-SApi-Nonce: abc123
X-SApi-Sign: 计算后的签名值
```

### 请求示例（单次全量）

```http
GET /sapi/jobs?status=1&pagination_enabled=0 HTTP/1.1
X-SApi-App-Key: sapi_xxxxxxxx
X-SApi-Timestamp: 1717488000
X-SApi-Nonce: abc123
X-SApi-Sign: 计算后的签名值
```

### 列表项字段

分页模式下字段位于 `data.data[]`；全量模式下位于 `data[]`。

## 2) 简历列表

- 接口：GET /sapi/resumes
- 描述：拉取候选人简历（不含已软删除）

### 专有 Query 参数

| 字段 | 是否必填 | 类型/规则 | 说明 |

| status | 否 | integer, in:0,1 | 1 正常 / 0 停用 |

## 3) 企业列表

- 接口：GET /sapi/companies
- 描述：拉取企业主体（不含已软删除）

### 专有 Query 参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| parent_id | 否 | integer, min:1 | 上级企业 ID |
| status | 否 | integer, in:0,1 | 1 启用 / 0 停用 |

### 请求示例

```http
GET /sapi/companies?status=1&updated_from=2026-06-01%2000:00:00 HTTP/1.1
X-SApi-App-Key: sapi_xxxxxxxx
X-SApi-Timestamp: 1717488000
X-SApi-Nonce: abc123
X-SApi-Sign: 计算后的签名值
```

### 列表项字段

| 字段 | 类型 | 说明 |

| id | int | 企业 ID |

## 4) 用户列表

- 接口：GET /sapi/users
- 描述：拉取平台用户（不含已软删除，不返回 password 字段）

### 专有 Query 参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| status | 否 | string, max:32 | 用户状态，如 active |

### 请求示例

```http
GET /sapi/users?status=active&per_page=100 HTTP/1.1
X-SApi-App-Key: sapi_xxxxxxxx

X-SApi-Nonce: abc123
X-SApi-Sign: 计算后的签名值
```

## 校验失败

参数格式错误时 HTTP 状态码 422，结构与 Laravel 默认校验响应一致。

## 业务错误

鉴权失败等业务错误 HTTP 状态码通常为 401；响应体含 `code` 与 `message`（具体见 [鉴权.md](./鉴权.md)）。
