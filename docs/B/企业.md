# 企业

## 说明

除“发送验证码 / 登录”外，本文档接口均需携带 B 端登录态 Token。

---

### 认证方式

请求头：

```http
Authorization: Bearer {access_token}
Accept: application/json
```

### 统一响应结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | HTTP 状态码（通常 `200`） |
| `data` | object\|array | 业务数据 |
| `meta` | object | 元信息 |
| `meta.timestamp` | float | 响应时间戳 |
| `meta.response_time` | float | 接口耗时（秒） |

---

## 企业列表

获取当前 B 端用户可访问的企业列表。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/companies` |

### 请求参数

无。

## 企业入驻（创建企业）

创建企业并自动将当前 B 端用户与企业建立关联。

> 说明：B 端创建企业时，企业状态会按服务逻辑初始化为“审批中”（`status = 2`）。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/companies` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 企业名称 |
| `credit_code` | string | 是 | 统一社会信用代码（唯一） |
| `legal_person` | string | 是 | 法人姓名 |
| `contact_phone` | string | 是 | 联系电话 |
| `address` | string | 否 | 企业地址 |

### 示例请求

```json
{
  "name": "南昌示例科技有限公司",
  "credit_code": "91360100MA0000000X",
  "legal_person": "李四",
  "contact_phone": "13900000000",
  "address": "南昌市高新区示例路 88 号"
}
```

### 示例响应

```json
{
  "code": 200,
  "data": {
    "id": 12,
    "name": "南昌示例科技有限公司",
    "credit_code": "91360100MA0000000X",
    "legal_person": "李四",
    "contact_phone": "13900000000",
    "address": "南昌市高新区示例路 88 号",
    "status": 2,
    "created_at": "2026-05-19T03:20:11.000000Z",
    "updated_at": "2026-05-19T03:20:11.000000Z"
  },
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.021
  }
}
```

## 编辑企业

更新指定企业信息。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `PUT` |
| URI | `/b/companies/{id}` |
| Content-Type | `application/json` |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | int | 是 | 企业 ID |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 企业名称 |
| `credit_code` | string | 是 | 统一社会信用代码（唯一，更新时忽略当前记录） |
| `legal_person` | string | 是 | 法人姓名 |
| `contact_phone` | string | 是 | 联系电话 |
| `address` | string | 否 | 企业地址 |

### 示例请求

```json
{
  "name": "南昌示例科技有限公司（更新）",
  "credit_code": "91360100MA0000000X",
  "legal_person": "李四",
  "contact_phone": "13900000001",
  "address": "南昌市红谷滩新区示例路 99 号"
}
```

### 示例响应

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.017
  }
}
```

---

## 状态值说明（CompanyStatus）

| 值 | 含义 |
|---|---|
| `0` | 禁用 |
| `1` | 启用 |
| `2` | 审批中 |
