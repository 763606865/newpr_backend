# 岗位

## 说明

岗位接口对应 `\App\B\Controllers\PositionController`。
所有接口均基于当前登录企业进行操作（由后端根据当前 Token 自动识别企业）。

---

### 认证方式

请求头：

```http
Authorization: Bearer {access_token}
Accept: application/json
```

### 统一响应结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | HTTP 状态码（通常 `200`） |
| `data` | object\|array | 业务数据 |
| `meta` | object | 元信息 |
| `meta.timestamp` | float | 响应时间戳 |
| `meta.response_time` | float | 接口耗时（秒） |

---

## 岗位列表

分页获取当前企业下的岗位列表。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/positions` |

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `keyword` | string | 否 | 关键字模糊搜索，匹配 `name`、`code` |
| `name` | string | 否 | 岗位名称模糊搜索 |
| `code` | string | 否 | 岗位编码模糊搜索 |
| `per_page` | int | 否 | 每页条数，默认 `20`，范围 `1-100` |

### 示例请求

```http
GET /b/positions?keyword=财务&name=经理&code=FIN&per_page=20
Authorization: Bearer {access_token}
Accept: application/json
```

## 创建岗位

在当前企业下创建岗位。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/positions` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 岗位名称，最大 100 字符 |
| `code` | string | 是 | 岗位编码，企业内唯一，最大 100 字符 |
| `sort` | int | 否 | 排序值，默认 `0` |
| `remark` | string | 否 | 备注，最大 255 字符 |

### 示例请求

```json
{
  "name": "财务经理",
  "code": "FIN_MANAGER",
  "sort": 20,
  "remark": "负责财务管理"
}
```

### 示例响应

```json
{
  "code": 200,
  "data": {
    "id": 9,
    "company_id": 12,
    "name": "财务经理",
    "code": "FIN_MANAGER",
    "sort": 20,
    "remark": "负责财务管理",
    "created_at": "2026-05-19T08:30:11.000000Z",
    "updated_at": "2026-05-19T08:30:11.000000Z"
  },
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.010
  }
}
```

## 删除岗位

删除当前企业下指定岗位。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `DELETE` |
| URI | `/b/positions/{id}` |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | int | 是 | 岗位 ID |

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.004
  }
}
```

### 失败响应示例（岗位下存在员工）

```json
{
  "code": 422,
  "message": "该岗位下存在员工，无法删除。",
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.002
  }
}
```

---

## 校验规则补充

- `code` 在同一企业内必须唯一（已过滤软删除数据）。
- 删除岗位前会检查是否已有员工关联该岗位。
