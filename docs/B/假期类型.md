# 假期类型

## 说明

假期类型接口对应 `\App\B\Controllers\LeaveTypeController`。
所有接口均基于当前登录企业进行操作。

---

### 认证方式

```http
Authorization: Bearer {access_token}
Accept: application/json
```

---

## 列表

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/leave-types` |

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `keyword` | string | 否 | 匹配 `name`、`code` |
| `name` | string | 否 | 假期名称模糊搜索 |
| `code` | string | 否 | 假期编码模糊搜索 |
| `deduction_type` | int | 否 | 扣薪类型：`1带薪`、`2半薪`、`3无薪` |
| `unit_type` | int | 否 | 单位：`1天`、`2小时` |
| `status` | int | 否 | 状态：`1启用`、`0停用` |
| `per_page` | int | 否 | 每页条数，默认 `20`，范围 `1-100` |

### 示例请求

```http
GET /b/leave-types?keyword=年假&deduction_type=1&status=1&per_page=20
Authorization: Bearer {access_token}
Accept: application/json
```

### 示例响应

```json
  "data": {
	"current_page": 1,
	"data": [
	  {
		"id": 5,
		"company_id": 12,

		"code": "ANNUAL",
		"deduction_type": 1,

		"status": 1
	  }
	],

  },

```

## 创建页数据

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/leave-types/create` |

### 响应字段

- `deduction_type_options`：扣薪类型选项
- `unit_type_options`：单位选项
- `status_options`：状态选项

---

## 创建

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/leave-types` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 假期名称，最大50字符 |
| `code` | string | 是 | 假期编码，企业内唯一，最大32字符 |
| `deduction_type` | int | 否 | 扣薪类型 |
| `unit_type` | int | 否 | 请假单位：`1按天`、`2按小时` |
| `min_duration` | number | 否 | 最小请假时长，默认0.5 |
| `need_attachment` | bool | 否 | 是否必须附件 |
| `allow_negative` | bool | 否 | 是否允许透支 |
| `max_continuous_days` | int | 否 | 最大连续请假天数 |
| `status` | int | 否 | 状态：`1启用`、`0停用` |

### 创建示例请求

```json
{
  "name": "年假",
  "code": "ANNUAL",
  "deduction_type": 1,
  "unit_type": 1,
  "min_duration": 0.5,
  "need_attachment": false,
  "allow_negative": false,
  "max_continuous_days": 15,
  "status": 1
}
```

### 创建示例响应

```json
{
  "code": 200,
  "data": {
	"id": 5,
	"company_id": 12,
	"name": "年假",
	"code": "ANNUAL",
	"deduction_type": 1,
	"unit_type": 1,
	"status": 1
  },
  "meta": {
	"timestamp": 1777435057.215031,
	"response_time": 0.008
  }
}
```
