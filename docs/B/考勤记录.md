# 考勤记录

## 说明

考勤记录接口对应 `\App\B\Controllers\AttendanceScheduleController`。
接口按“员工月度明细”场景设计，仅提供列表、详情、导出能力。
所有接口均基于当前登录企业进行操作。

---

### 认证方式

```http
Authorization: Bearer {access_token}
Accept: application/json
```

---

## 月度考勤列表

分页获取员工维度的月度考勤汇总。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/attendance-schedules` |

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `month` | string | 否 | 月份，格式 `YYYY-MM`，未传默认当前月 |
| `keyword` | string | 否 | 匹配员工工号/姓名/手机号 |
| `employee_no` | string | 否 | 员工工号模糊搜索 |
| `real_name` | string | 否 | 员工姓名模糊搜索 |
| `department_id` | int | 否 | 部门ID |
| `employee_id` | int | 否 | 员工ID |
| `status` | int | 否 | 状态：`0待计算`、`1正常`、`2迟到`、`3早退`、`4缺卡`、`5旷工` |
| `per_page` | int | 否 | 每页条数，默认 `20`，范围 `1-100` |

### 示例请求

```http
GET /b/attendance-schedules?month=2026-05&keyword=张三&department_id=10&per_page=20
Authorization: Bearer {access_token}
Accept: application/json
```

## 员工月度考勤明细

获取单个员工在指定月份的每日考勤记录和汇总。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/attendance-schedules/{id}` |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | int | 是 | 员工ID |

|---|---|---|---|
| `month` | string | 否 | 月份，格式 `YYYY-MM`，未传默认当前月 |

## 导出月度考勤明细

导出同筛选条件下的考勤明细 CSV。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/attendance-schedules/export` |

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `month` | string | 否 | 月份，格式 `YYYY-MM`，未传默认当前月 |
| `keyword` | string | 否 | 员工工号/姓名/手机号 |
| `department_id` | int | 否 | 部门ID |
| `employee_id` | int | 否 | 员工ID |
| `status` | int | 否 | 状态：`0待计算`、`1正常`、`2迟到`、`3早退`、`4缺卡`、`5旷工` |

### 示例请求

```http
GET /b/attendance-schedules/export?month=2026-05&department_id=10
Authorization: Bearer {access_token}
Accept: text/csv
```

### 响应说明

- 返回 CSV 文件下载。
- 文件名格式：`attendance-schedules-{YYYY-MM}.csv`。
- 表头字段：`日期`、`部门`、`员工工号`、`员工姓名`、`考勤规则`、`状态`、`是否休息日`、`标准工时`、`实际工时`、`迟到分钟`、`早退分钟`、`缺勤分钟`。

---

## 说明补充

- 时间是重要筛选维度：若不传 `month`，后端默认按当前月份筛选。
- `index` 为员工月度汇总，`show` 为单员工月度明细，`export` 为同筛选条件的明细导出。
