# 部门

## 说明

部门接口对应 `\App\B\Controllers\DepartmentController`。
所有接口均基于当前登录企业进行操作（由后端根据当前 Token 自动识别企业）。

---

### 认证方式

请求头：

```http
Authorization: Bearer {access_token}
Accept: application/json
```

### 统一响应结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | HTTP 状态码（通常 `200`） |
| `data` | object\|array | 业务数据 |
| `meta` | object | 元信息 |
| `meta.timestamp` | float | 响应时间戳 |
| `meta.response_time` | float | 接口耗时（秒） |

---

## 部门列表

获取当前企业的部门列表，默认返回树状结构。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/departments` |

### 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `flat` | bool | 否 | `false` | `true/1` 返回平铺列表；否则返回树状结构 |
| `with_employees` | bool | 否 | `false` | `true/1` 时预加载每个部门的员工列表 |

### 示例请求

```http
GET /b/departments
```

```http
GET /b/departments?flat=1
```

```http
GET /b/departments?with_employees=1
```

## 创建部门

在当前企业下创建新部门。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/departments` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 部门名称，最大 100 字符 |
| `parent_id` | int | 否 | 上级部门 ID，默认 `0`（顶级部门） |
| `type` | int | 是 | 部门类型，见下方 `DepartmentType` |
| `sort` | int | 否 | 排序值，默认 `0` |
| `remark` | string | 否 | 备注，最大 255 字符 |

### 示例请求

```json
{
  "name": "财务部",
  "parent_id": 1,
  "type": 1,
  "sort": 10,
  "remark": "负责公司财务管理"
}
```

### 示例响应

```json
{
  "code": 200,
  "data": {
    "id": 9,
    "company_id": 12,
    "parent_id": 1,
    "name": "财务部",
    "type": 1,
    "sort": 10,
    "remark": "负责公司财务管理",
    "created_at": "2026-05-19T06:20:11.000000Z",
    "updated_at": "2026-05-19T06:20:11.000000Z"
  },
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.015
  }
}
```

## 枚举说明（DepartmentType）

| 值 | 含义 |
|---|---|
| `1` | 职能 |
| `2` | 业务 |
| `3` | 管理层 |

## 校验规则补充

- `parent_id = 0` 表示顶级部门。
- `parent_id > 0` 时，必须是当前企业下已存在的部门。
- 更新时，`parent_id` 不能等于当前部门自身 ID。
