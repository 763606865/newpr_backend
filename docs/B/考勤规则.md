# 考勤规则

## 说明

考勤规则接口对应 `\App\B\Controllers\AttendanceRuleController`。
所有接口均基于当前登录企业进行操作。

---

### 认证方式

```http
Authorization: Bearer {access_token}
Accept: application/json
```

---

## 列表

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/attendance-rules` |

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `keyword` | string | 否 | 匹配 `name`、`code` |
| `name` | string | 否 | 规则名称模糊搜索 |
| `code` | string | 否 | 规则编码模糊搜索 |
| `work_type` | int | 否 | 工作类型：`1固定`、`2分段`、`3弹性` |
| `status` | int | 否 | 状态：`1启用`、`0停用` |
| `per_page` | int | 否 | 每页条数，默认 `20`，范围 `1-100` |

### 示例请求

```http
GET /b/attendance-rules?keyword=行政&work_type=1&status=1&per_page=20
Authorization: Bearer {access_token}
Accept: application/json
```

### 示例响应

```json
{
  "code": 200,
  "data": {
	"current_page": 1,
	"data": [
	  {
		"id": 1,
		"company_id": 12,
		"name": "行政班",
		"code": "AR-HR-001",
		"work_type": 1,
		"status": 1
	  }
	],
	"per_page": 20,
	"total": 1
  },
  "meta": {
	"timestamp": 1777435057.215031,
	"response_time": 0.006
  }
}
```

## 创建页数据

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `GET` |
| URI | `/b/attendance-rules/create` |

### 响应字段

- `departments`：当前企业部门列表
- `work_type_options`：工作类型选项
- `status_options`：状态选项

---

## 创建

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/attendance-rules` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 规则名称，最大100字符 |
| `code` | string | 是 | 规则编码，最大100字符 |
| `work_type` | int | 否 | `1/2/3` |
| `start_time` | string | 否 | 上班时间，格式 `HH:mm` |
| `end_time` | string | 否 | 下班时间，格式 `HH:mm` |
| `time_segments` | array | 否 | 分段时间配置 |
| `core_start_time` | string | 否 | 核心开始时间 |
| `core_end_time` | string | 否 | 核心结束时间 |
| `required_work_hours` | number | 否 | 要求工时 |
| `is_overnight` | bool | 否 | 是否跨天 |
| `rest_duration_mins` | int | 否 | 休息时长（分钟） |
| `late_grace_mins` | int | 否 | 迟到容忍分钟 |
| `early_leave_grace_mins` | int | 否 | 早退容忍分钟 |
| `clock_in_window_mins` | int | 否 | 上班打卡窗口 |
| `clock_out_window_mins` | int | 否 | 下班打卡窗口 |
| `applicable_scope` | array | 否 | 适用范围配置 |
| `status` | int | 否 | `1`启用，`0`停用 |
| `extra` | array | 否 | 扩展配置 |

### 创建示例请求

```json
{
  "name": "行政班",
  "code": "AR-HR-001",
  "work_type": 1,
  "start_time": "09:00",
  "end_time": "18:00",
  "rest_duration_mins": 60,
  "late_grace_mins": 10,
  "early_leave_grace_mins": 10,
  "status": 1
}
```

### 创建示例响应

```json
{
  "code": 200,
  "data": {
	"id": 1,
	"company_id": 12,
	"name": "行政班",
	"code": "AR-HR-001",
	"work_type": 1,
	"status": 1
  },
  "meta": {
	"timestamp": 1777435057.215031,
	"response_time": 0.009
  }
}
```

## 删除

| 字段 | 值 |
|---|---|
| 方法 | `DELETE` |
| URI | `/b/attendance-rules/{id}` |

### 删除限制

- 已被考勤分配使用时不可删除。
- 已生成考勤记录时不可删除。
