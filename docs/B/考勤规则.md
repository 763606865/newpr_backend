# 考勤规则

## 说明

考勤规则接口对应 `\App\B\Controllers\AttendanceRuleController`。
所有接口均基于当前登录企业进行操作。

> 当前“大小周 / 做X休Y”这类**排班周期配置**，并不存放在考勤规则本身，
> 而是存放在员工考勤分配 `AttendanceAssignment` 中。
> 其中：
>
> - `cycle_type`：周期类型
> - `work_days` / `rest_days`：周期工作天数 / 休息天数
> - `start_anchor_date`：周期锚点日期
> - `extra`：用于补充大小周的具体休息日配置

---

### 认证方式

```http
Authorization: Bearer {access_token}
Accept: application/json
```

| `core_start_time` | string | 否 | 核心开始时间 |
| `core_end_time` | string | 否 | 核心结束时间 |
| `required_work_hours` | number | 否 | 要求工时 |
| `is_overnight` | bool | 否 | 是否跨天 |
| `rest_duration_mins` | int | 否 | 休息时长（分钟） |
| `late_grace_mins` | int | 否 | 迟到容忍分钟 |
| `early_leave_grace_mins` | int | 否 | 早退容忍分钟 |
| `clock_in_window_mins` | int | 否 | 上班打卡窗口 |
| `clock_out_window_mins` | int | 否 | 下班打卡窗口 |
| `applicable_scope` | array | 否 | 适用范围配置 |
| `status` | int | 否 | `1`启用，`0`停用 |

### `extra` 说明

当前 `AttendanceRule.extra` 仅建议用于放置规则层面的补充配置。

如果是“大小周 / 做X休Y”这种**员工排班周期**配置，请放在 `AttendanceAssignment.extra`，不要放在规则 `extra` 中。

## 大小周排班配置说明

### 适用位置

大小周配置用于每日定时生成 `AttendanceSchedule`，配置位置在员工考勤分配 `AttendanceAssignment`：

| 字段 | 说明 |
| --- | --- |
| `cycle_type` | 周期类型，`2` 表示大小周 |
| `start_anchor_date` | 锚点日期，系统会以其所在周作为大小周轮转起点 |
| `extra.start_week_type` | 锚点周类型：`big` / `small` |
| `extra.big_week_rest_weekdays` | 大周休息日数组 |
| `extra.small_week_rest_weekdays` | 小周休息日数组 |

### 星期值约定

休息日数组使用 Carbon 的星期值：

| 值 | 星期 |
| --- | --- |
| `0` | 周日 |
| `1` | 周一 |
| `2` | 周二 |
| `3` | 周三 |
| `4` | 周四 |
| `5` | 周五 |
| `6` | 周六 |

### 推荐配置示例

#### 大周单休，小周双休

```json
{
  "cycle_type": 2,
  "start_anchor_date": "2026-05-19",
  "extra": {
	"start_week_type": "big",
	"big_week_rest_weekdays": [0],
	"small_week_rest_weekdays": [6, 0]
  }
}
```

含义：

- 锚点周为大周
- 大周周日休息
- 小周周六、周日休息

### 当前生成规则说明

每日定时任务在生成 `AttendanceSchedule` 时，当前采用以下规则：

1. 以 `start_anchor_date` 所在周为轮转起点；为空时回退到 `effective_start_date`
2. 以**周一**作为一周起始
3. 按“大周 / 小周”交替轮转
4. 若未传 `extra.big_week_rest_weekdays` / `extra.small_week_rest_weekdays`，默认：
   - 大周：周日休息
   - 小周：周六、周日休息

### 创建示例请求

```json
{
  "name": "行政班",
  "code": "AR-HR-001",
  "work_type": 1,
  "start_time": "09:00",

```
