# 认证

## 说明

B 端认证接口对应 `\App\B\Controllers\AuthController`。

- 无需登录即可访问：`发送验证码`、`手机号登录`
- 需要登录（`auth:b`）：`刷新 Token`、`获取用户信息`、`登出`

---

### 认证方式

请求头：

```http
Authorization: Bearer {access_token}
Accept: application/json
```

### 统一响应结构（大多数接口）

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | HTTP 状态码（通常 `200`） |
| `data` | object\|array | 业务数据 |
| `meta` | object | 元信息 |
| `meta.timestamp` | float | 响应时间戳 |
| `meta.response_time` | float | 接口耗时（秒） |

> 注意：`登出`接口当前直接返回 `{"message": "Successfully logged out"}`，结构与上表不同（以代码实现为准）。

> 补充：登录/刷新/获取用户信息中的 `current_company` 会携带企业当前套餐下的 `menus` 与 `features`（取自 `ship_company_biz_plans` 快照）。

### `current_company` 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | int | 当前企业 ID |
| `name` | string | 企业名称 |
| `status` | int | 企业状态 |
| `address` | string | 企业地址 |
| `last_login_ip` | string | 当前用户在该企业最近登录 IP |
| `last_login_at` | string\|null | 当前用户在该企业最近登录时间 |
| `plan` | object\|null | 当前生效套餐快照 |
| `plan.id` | int | 套餐 ID |
| `plan.name` | string | 套餐名称 |
| `plan.code` | string | 套餐编码 |
| `plan.start_time` | string\|null | 套餐开始时间 |
| `plan.end_time` | string\|null | 套餐结束时间 |
| `menus` | array | 套餐可用菜单（用于菜单权限） |
| `features` | array | 套餐可用功能点（用于按钮/能力权限） |

> 若当前 Token 未绑定企业，`current_company` 返回 `null`。

## 发送验证码

向手机号发送登录验证码（场景固定为 `b-login`）。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/send-verification-code` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `phone` | string | 是 | 手机号，最大长度 13 |

### 示例请求

```json
{
  "phone": "16600000000"
}
```

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.013
  }
}
```

### 失败响应示例（频率限制）

```json
{
  "code": 429,
  "message": "请求过于频繁，请稍后再试",
  "errors": {
    "expires_in": 54
  },
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.003
  }
}
```

## 手机号登录

通过手机号 + 验证码登录；若手机号未注册，系统会自动创建 B 端用户。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/login` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `phone` | string | 是 | 手机号，最大长度 13 |
| `code` | string | 是 | 验证码，最大长度 6 |

## 刷新 Token

用于在已登录状态下刷新访问令牌，可选切换企业上下文。

- 传 `company_id`：切换到指定企业并签发新 token
- 不传 `company_id`：按当前 token 绑定企业续期

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/refresh-token` |
| 鉴权 | `Bearer Token`（必填） |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `company_id` | int | 否 | 目标企业 ID |

### 示例请求（续期）

```json
{}
```

### 示例请求（切换企业后续期）

```json
{
  "company_id": 12
}
```

## 登出

吊销当前访问 token。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/logout` |
| 鉴权 | `Bearer Token`（必填） |

### 成功响应示例

```json
{
  "message": "Successfully logged out"
}
```
