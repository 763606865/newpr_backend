# 认证

## 说明

B 端认证接口对应 `\App\B\Controllers\AuthController`。

- 无需登录即可访问：`发送验证码`、`手机号登录`
- 需要登录（`auth:b`）：`刷新 Token`、`获取用户信息`、`登出`

---

### 认证方式

请求头：

```http
Authorization: Bearer {access_token}
Accept: application/json
```

### 统一响应结构（大多数接口）

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | HTTP 状态码（通常 `200`） |
| `data` | object\|array | 业务数据 |
| `meta` | object | 元信息 |
| `meta.timestamp` | float | 响应时间戳 |
| `meta.response_time` | float | 接口耗时（秒） |

> 注意：`登出`接口当前直接返回 `{"message": "Successfully logged out"}`，结构与上表不同（以代码实现为准）。

---

## 发送验证码

向手机号发送登录验证码（场景固定为 `b-login`）。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/send-verification-code` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `phone` | string | 是 | 手机号，最大长度 13 |

### 示例请求

```json
{
  "phone": "16600000000"
}
```

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.013
  }
}
```

### 失败响应示例（频率限制）

```json
{
  "code": 429,
  "message": "请求过于频繁，请稍后再试",
  "errors": {
    "expires_in": 54
  },
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.003
  }
}
```

## 手机号登录

通过手机号 + 验证码登录；若手机号未注册，系统会自动创建 B 端用户。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/login` |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `phone` | string | 是 | 手机号，最大长度 13 |
| `code` | string | 是 | 验证码，最大长度 6 |

### 示例请求

```json
{
  "phone": "16600000000",
  "code": "123456"
}
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "token_type": "Bearer",
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiJ9...",
    "user": {
      "id": 1,
      "name": "",
      "phone": "16600000000",
      "email": "",
      "avatar": "",
      "last_login_ip": "127.0.0.1",
      "last_login_at": "2026-05-19 16:00:11",
      "current_company": null,
      "companies": []
    }
  },
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.019
  }
}
```

### 失败响应示例（验证码错误）

```json
{
  "code": 422,
  "message": "验证码错误或已失效。",
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.004
  }
}
```

## 刷新 Token

用于在已登录状态下刷新访问令牌，可选切换企业上下文。

- 传 `company_id`：切换到指定企业并签发新 token
- 不传 `company_id`：按当前 token 绑定企业续期

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/refresh-token` |
| 鉴权 | `Bearer Token`（必填） |
| Content-Type | `application/json` |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `company_id` | int | 否 | 目标企业 ID |

### 示例请求（续期）

```json
{}
```

### 示例请求（切换企业后续期）

```json
{
  "company_id": 12
}
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "token_type": "Bearer",
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiJ9...",
    "user": {
      "id": 1,
      "name": "张三",
      "phone": "16600000000",
      "email": "",
      "avatar": "",
      "last_login_ip": "127.0.0.1",
      "last_login_at": "2026-05-19 15:30:11",
      "current_company": {
        "id": 12,
        "name": "南昌示例科技有限公司",
        "status": 2
      },
      "companies": []
    }
  },
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.014
  }
}
```

### 失败响应示例（`company_id` 非法）

```json
{
  "code": 422,
  "message": "company_id 参数无效。",
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.002
  }
}
```

### 失败响应示例（无权切换企业）

```json
{
  "code": 403,
  "message": "无权切换到该企业。",
  "meta": {
    "timestamp": 1777435057.215031,
    "response_time": 0.002
  }
}
```

## 登出

吊销当前访问 token。

### 请求详情

| 字段 | 值 |
|---|---|
| 方法 | `POST` |
| URI | `/b/auth/logout` |
| 鉴权 | `Bearer Token`（必填） |

### 成功响应示例

```json
{
  "message": "Successfully logged out"
}
```
