# 认证

本文档对应 `app/Api/Controllers/AuthController.php` 当前实现。

> 相关文档：打卡接口见 `docs/Api/打卡.md`。

## 通用说明

- 认证方式：`Authorization: Bearer {access_token}`
- 除登录/验证码/找回密码外，其余接口均需登录
- 成功响应统一为：`code + data + meta`
- 错误响应统一为：`code + message + meta`（`debug` 开启时可能包含 `errors`）

---

## 1. 发送验证码

- 方法：`POST`
- URI：`/api/auth/send-verification-code`
- 鉴权：否

### 请求体（JSON）

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 发送类型：`phone` / `email` |
| `account` | string | 是 | 手机号或邮箱 |
| `scene` | string | 是 | 场景：`login` / `forgot_password` |

### 示例请求

```json
{
  "type": "phone",
  "account": "13800138000",
  "scene": "login"
}
```

### 示例响应

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1777435057.21,
    "response_time": 0.03
  }
}
```

## 6. 刷新 Token

- 方法：`POST`
- URI：`/api/auth/refresh-token`
- 鉴权：是

### 请求体（JSON）

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `employee_id` | int | 否 | 切换当前员工身份 |

### 说明

- 不传 `employee_id`：沿用当前 token 的 `responsible`
- 传 `employee_id`：必须属于当前登录用户且为 active 员工，否则返回 `403`
