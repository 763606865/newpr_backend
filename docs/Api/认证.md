# 认证

## 发送验证码

向指定账户发送验证码（短信验证码），用于发起认证流程，如登录或注册。

---

### 请求详情

| 字段  | 值                                  |
|-----|------------------------------------|
| 方法  | `POST`                             |
| URI | `/api/auth/send-verification-code` |

---

### 请求体

Content-Type: `application/json`

| 参数        | 类型     | 必填 | 描述                           |
|-----------|--------|----|------------------------------|
| `type`    | string | 是  | 验证码发送方式。支持值：`phone`、`email`。 |
| `account` | string | 是  | 接收验证码的目标账户（例如手机号）。           |
| `scene`   | string | 是  | 触发验证码请求的使用场景。见下方说明。          |

---

### 场景值

`scene` 参数表示请求验证码的上下文。常见值包括：

| 值          | 描述         |
|------------|------------|
| `login`    | 用户正在尝试登录。  |
| `register` | 用户正在注册新账户。 |
| `reset`    | 用户正在重置密码。  |

> **注意：** 请确保传递正确的 `scene` 值，以避免服务器端验证码验证失败。

---

### 示例请求体

```json
{
    "type": "phone",
    "account": "166****0",
    "scene": "login"
}
```

### 响应体

Content-Type: `application/json`

| 参数                   | 类型     | 描述       |
|----------------------|--------|----------|
| `code`               | int    | 状态码。     |
| `data`               | object | 响应内容。    |
| `meta`               | object | Meta     |
| `meta.timestamp`     | float  | 服务器响应时间戳 |
| `meta.response_time` | float  | 响应时间     |

---

### 示例响应体

```json
{
    "code": 200,
    "data": [],
    "meta": {
        "timestamp": 1777435057.215031,
        "response_time": 0.3013138771057129
    }
}
```

## 手机号登录

通过**手机号和短信验证码**认证用户。此端点通过验证提供的手机号与通过短信发送的一次性验证码来进行手机号登录。

> **注意：** 短信验证码（`code`）必须在请求此端点之前通过调用验证码端点获取。验证码通常是短期的，并在设定时间后过期。

---

### 请求体 (form-data)

| 参数      | 类型     | 必填 | 描述 |
|-----------|--------|---|-------------|
| `phone`   | string | 是 | 用户注册的手机号。 |
| `code`    | string | 是 | 发送到手机号的短信验证码。 |

---

### 请求体 (form-data)

| 参数      | 类型     | 必填 | 描述 |
|-----------|--------|---|-------------|
| `phone`   | string | 是 | 用户注册的手机号。 |
| `code`    | string | 是 | 发送到手机号的短信验证码。 |
