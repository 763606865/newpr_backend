# 数据库表结构

> 用途：中台搭建时对接各分站主数据结构（首批：`companies`、`departments`、`employees`、`users`、`rc_jobs`、`rc_resumes`、`rc_resume_*`、`cms_announcements`）。  
> 来源：`database/migrations/2026_04_03_022020_create_company_tables.php`、`database/migrations/2026_06_04_164129_create_company_info_tables.php`、`database/migrations/0001_01_01_000000_create_users_table.php`、`database/migrations/2026_05_28_090438_create_rc_tables.php`、`database/migrations/2026_06_01_145551_create_resume_tables.php`、`database/migrations/2026_06_09_171347_change_political_status_to_enum_on_rc_resumes_table.php`、`database/migrations/2026_05_27_172810_create_cms_tables.php` 以及对应 Enum。

## 统一约定

- 时间字段统一为 `timestamp`（或 `datetime`）类型。
- 能用 `int` 的枚举字段尽量用 `int`。
- 软删除字段统一为 `deleted_at`。
- 以下结构为对接视角（字段名与库表保持一致）。

## 1) companies（企业主体表）

```jsonc
{
  "id": 1, // bigint unsigned
  "parent_id": null, // bigint unsigned|null, 上级企业ID（集团总部/独立企业为 null）
  "depth": 1, // int, 集团层级深度（1=集团根或独立企业）
  "name": "企业名称", // string
  "credit_code": "统一社会信用代码", // string|null, unique
  "legal_person": "法人姓名", // string|null
  "contact_phone": "联系电话", // string|null
  "address": "企业地址", // text|null
  "status": 1, // int
  "statusList": [
    { "id": 0, "name": "禁用" },
    { "id": 1, "name": "启用" },
    { "id": 2, "name": "审批中" }
  ],
  "created_at": "创建时间", // timestamp
  "updated_at": "更新时间", // timestamp
  "deleted_at": "删除时间" // timestamp|null
}
```

### 约束/索引

- 唯一索引：`credit_code`。
- 普通索引：`parent_id`、`(parent_id, status)`。
- `parent_id = null` 表示集团总部或独立法人；子公司 `parent_id` 指向集团企业 `id`。

### DDL（参考）

```sql
create table newpr.companies
(
    id            bigint unsigned auto_increment
        primary key,
    parent_id     bigint unsigned   null comment '上级企业ID（集团总部/独立企业为 null，子公司指向集团）',
    depth         tinyint unsigned  default 1 not null comment '集团层级深度（1=集团根或独立企业）',
    name          varchar(255)      not null comment '企业名称',
    credit_code   varchar(255)      null comment '统一社会信用代码',
    legal_person  varchar(255)      null comment '法人姓名',
    contact_phone varchar(255)      null comment '联系电话',
    address       text              null comment '企业地址',
    status        tinyint default 1 not null comment '状态',
    created_at    timestamp         null,
    updated_at    timestamp         null,
    deleted_at    timestamp         null,
    constraint companies_credit_code_unique
        unique (credit_code),
    index companies_parent_id_index (parent_id),
    index companies_parent_id_status_index (parent_id, status)
)
    comment '企业主体表' collate = utf8mb4_unicode_ci;
```

## 8) 关系参考（中台对接建议）

- `companies.id` 1 - n `departments.company_id`
- `companies.id` 1 - n `employees.company_id`
- `companies.id` 1 - n `rc_jobs.company_id`
- `companies.id` 1 - 1 `company_profiles.company_id`（可选）
- `departments.id` 1 - n `employees.department_id`
- `departments.id` 1 - n `rc_jobs.department_id`（可选）
- `users.id` 1 - n `employees.user_id`
- `users.id` 1 - n `rc_resumes.user_id`
- `users.id` 1 - n `rc_jobs.creator_user_id`（可选）
- `rc_resumes.id` 1 - n `rc_resume_*.resume_id`（求职意向、工作/教育/项目等子表）
- `rc_positions.code` 1 - n `rc_jobs.position_code`（逻辑关联，无显式外键）
- `rc_positions.id` 1 - n `rc_resume_intentions.expected_position_id`（逻辑关联）

> 说明：当前迁移中未显式声明外键约束，但业务上按上述关系关联。
