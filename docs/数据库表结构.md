# 数据库表结构

> 用途：中台搭建时对接各分站主数据结构（首批：`companies`、`departments`、`employees`、`users`）。  
> 来源：`database/migrations/2026_04_03_022020_create_company_tables.php`、`database/migrations/0001_01_01_000000_create_users_table.php` 以及对应 Enum。

## 统一约定

- 时间字段统一为 `timestamp`（或 `datetime`）类型。
- 能用 `int` 的枚举字段尽量用 `int`。
- 软删除字段统一为 `deleted_at`。
- 以下结构为对接视角（字段名与库表保持一致）。

```jsonc
{
  "id": 1, // bigint unsigned
  "name": "企业名称", // string
  "credit_code": "统一社会信用代码", // string|null, unique
  "legal_person": "法人姓名", // string|null
  "contact_phone": "联系电话", // string|null
  "address": "企业地址", // text|null
  "status": 1, // int
  "statusList": [
    { "id": 0, "name": "禁用" },
    { "id": 1, "name": "启用" },
    { "id": 2, "name": "审批中" }
  ],
  "created_at": "创建时间", // timestamp
  "updated_at": "更新时间", // timestamp
  "deleted_at": "删除时间" // timestamp|null
}
```

### 约束/索引

- 唯一索引：`credit_code`。

### DDL（参考）

```sql
create table newpr.companies
(
    id            bigint unsigned auto_increment
        primary key,
    name          varchar(255)      not null comment '企业名称',
    credit_code   varchar(255)      null comment '统一社会信用代码',
    legal_person  varchar(255)      null comment '法人姓名',
    contact_phone varchar(255)      null comment '联系电话',
    address       text              null comment '企业地址',
    status        tinyint default 1 not null comment '状态',
    created_at    timestamp         null,
    updated_at    timestamp         null,
    deleted_at    timestamp         null,
    constraint companies_credit_code_unique
        unique (credit_code)
)
    comment '企业主体表' collate = utf8mb4_unicode_ci;
```

```jsonc
{
  "id": 1, // bigint unsigned
  "company_id": 1, // bigint unsigned

  "depth": 1, // int, 层级
  "name": "部门名称", // string
  "type": 1, // int
  "typeList": [
    { "id": 1, "name": "职能" },
    { "id": 2, "name": "业务" },
    { "id": 3, "name": "管理层" }
  ],
  "sort": 0, // int
  "remark": "备注", // string|null
  "created_at": "创建时间", // timestamp
  "updated_at": "更新时间", // timestamp
  "deleted_at": "删除时间" // timestamp|null
}
```

### 约束/索引

- 普通索引：`(company_id, parent_id)`。

### DDL（参考）

```sql
create table newpr.departments
(
    id         bigint unsigned auto_increment
        primary key,
    company_id bigint unsigned                not null,
    parent_id  bigint unsigned default 0      not null comment '上级部门ID',
    depth      tinyint          default 1     null comment '层级',
    name       varchar(255)                  not null comment '部门名称',
    type       tinyint          default 1     not null comment '类型',
    sort       int              default 0     not null,
    remark     varchar(255)                  null,
    created_at timestamp                     null,
    updated_at timestamp                     null,
    deleted_at timestamp                     null,
    index departments_company_id_parent_id_index (company_id, parent_id)
)
    comment '企业部门架构表' collate = utf8mb4_unicode_ci;
```

### 约束/索引

- 普通索引：`company_id`、`department_id`、`position_id`、`user_id`、`entry_time`。

### DDL（参考）

```sql
create table newpr.employees
(
    id            bigint unsigned auto_increment
        primary key,
    user_id       bigint unsigned                null comment '关联用户ID',
    company_id    bigint unsigned                null comment '企业ID',
    department_id bigint unsigned                null comment '部门ID',
    position_id   bigint unsigned                null comment '职位ID',
    employee_no   varchar(255)                   null comment '员工工号',
    real_name     varchar(255)                   not null comment '姓名',
    avatar        varchar(255)                   not null comment '头像',
    email         varchar(255)                   null comment '邮箱',
    mobile        varchar(255)                   null comment '手机号',
    status        tinyint          default 1     not null comment '状态',
    entry_time    timestamp                      null comment '加入时间',
    created_at    timestamp                      null,
    updated_at    timestamp                      null,
    deleted_at    timestamp                      null,
    index employees_company_id_index (company_id),
    index employees_department_id_index (department_id),
    index employees_position_id_index (position_id),
    index employees_user_id_index (user_id),
    index employees_entry_time_index (entry_time)
)
    comment '员工表' collate = utf8mb4_unicode_ci;
```

### 约束/索引

- 唯一索引：`uuid`、`phone`、`wechat_unionid`。

### DDL（参考）

```sql
create table newpr.users
(
    id            bigint unsigned auto_increment
        primary key,
    uuid          binary(16)                       not null comment '全局唯一用户标识(UUID v4/v7)',
    name          varchar(50)                      null comment '真实姓名',
    nickname      varchar(50)                      null comment '昵称',
    phone         varchar(30)                      not null,
    email         varchar(100)                     not null,
    avatar        varchar(255)                     not null comment '头像',
    gender        tinyint            default 0     null comment '性别',
    password      varchar(255)                     null comment '密码',
    status        varchar(255)       default 'active' not null comment '用户状态',
    wechat_unionid varchar(64)                     null comment '微信UnionID',
    extra         mediumtext                       null comment '扩展信息',
    last_login_ip varchar(255)                     null comment '最后登录IP',
    last_login_at timestamp                        null comment '最后登录时间',
    created_at    timestamp                        null,
    updated_at    timestamp                        null,
    deleted_at    timestamp                        null,
    constraint users_uuid_unique
        unique (uuid),
    constraint users_phone_unique
        unique (phone),
    constraint users_wechat_unionid_unique
        unique (wechat_unionid)
)
    collate = utf8mb4_unicode_ci;
```

## 5) 关系参考（中台对接建议）

- `companies.id` 1 - n `departments.company_id`
- `companies.id` 1 - n `employees.company_id`
- `departments.id` 1 - n `employees.department_id`
- `users.id` 1 - n `employees.user_id`
