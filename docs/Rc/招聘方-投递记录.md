# 招聘方 - 投递记录列表

对应实现：`app/Rc/Controllers/CompanyApplicationController.php@index`

- 方法：`GET`
- URI：`/rc/companies/applications`
- 鉴权：是（需切换到招聘方身份并绑定企业）

## 请求参数（Query）

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| per_page | integer | 否 | 每页数量，默认 15 |
| job_id | integer | 否 | 按职位过滤 |
| status | integer | 否 | 按投递状态过滤（枚举值） |
| candidate_user_id | integer | 否 | 按候选人 user_id 过滤 |

## 示例请求

```
GET /rc/companies/applications?per_page=20&job_id=123
Authorization: Bearer {token}
```

## 示例响应（200）

```json
{
  "code": 200,
  "data": [
    {
      "id": 123,
      "company_id": 45,
      "job_id": 678,
      "candidate_user_id": 999,
      "resume_snapshot": {},
      "status": 1,
      "applied_at": "2026-07-14T10:00:00Z"
    }
  ],
  "meta": {
    "current_page": 1,
    "per_page": 20,
    "total": 1
  }
}
```

## 错误示例（未绑定企业）

```json
{
  "code": 422,
  "message": "请先切换为招聘方身份并绑定企业。"
}
```
