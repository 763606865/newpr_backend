# 学校（校招负责人绑定/资料）

## 说明

- 路由前缀：`/rc`
- 鉴权：均需 `Bearer Token`，并使用 `auth:rc`
- 适用对象：校招负责人身份（`identity_type = 3`）
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`

> 绑定成功后，校招负责人身份的 `has_basic_info` 为 `true`（`organization_type = school` 且 `organization_id` 不为空）。

### 前端入参说明

绑定接口提交 `school_code` 与 `job_title`。`school_code` 来自 `GET /rc/meta/schools` 或 `GET /rc/meta` 中 `schools[].value`。

绑定成功后，服务端会自动创建 `school_profiles` 记录（`status = 2` 审核中），校招负责人可通过 `PUT /rc/schools/profile` 完善院校展示资料。

Logo、横幅图、资质证明需先 `POST /rc/upload`，将 `data.path` 填入对应字段。

## 1) 绑定已存在学校

- 接口：`POST /rc/schools/bind`
- Content-Type：`application/json`
- 描述：将当前校招负责人身份绑定到已有学校；若资料不存在则自动创建

### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `school_code` | 是 | `required`, `string`, `max:30`, `exists:schools,school_code` | 学校代码（来自 Meta 字典 `schools[].value`） |
| `job_title` | 是 | `required`, `string`, `max:50` | 岗位名称 |

### 请求示例

```json
{
  "school_code": "4111010001",
  "job_title": "就业办主任"
}
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "school": {
      "id": 1,
      "name": "北京大学",
      "school_code": "4111010001",
      "province": "北京市",
      "city": "北京市",
      "competent_dept": "教育部",
      "type": "本科",
      "profile": {
        "school_code": "4111010001",
        "competent_dept": "教育部",
        "status": 2,
        "status_label": "审核中",
        "allow_company_apply_activity": true,
        "allow_company_cooperate_apply": true,
        "campus_count": 0,
        "department_count": 0,
        "cooperate_company_count": 0,
        "activity_total": 0,
        "education_levels": [],
        "education_level_labels": []
      }
    },
    "identity": {
      "id": 10,
      "organization_type": "school",
      "organization_id": 1,
      "organization_name": "北京大学",
      "identity_type": 3,
      "identity_name": "校招负责人",
      "job_title": "就业办主任",
      "has_basic_info": true
    }
  },
  "meta": {
    "timestamp": 1748865600.1234,
    "response_time": 0.0123
  }
}
```

### 成功响应 `data`

| 字段 | 说明 |
|------|------|
| `school` | 学校对象（含 `profile`） |
| `identity` | 绑定后的校招负责人身份 |

### 业务失败

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为校招负责人身份。 |
| `422` | 您已绑定该学校。 |
| `422` | 该学校已被禁用，无法绑定。 |
| `404` | 学校不存在。 |

> 当前 Token 对应校招负责人身份已绑定其他学校时，会**新建一条**校招负责人身份行并绑定目标学校（同一用户可拥有多所学校身份，切换见 `POST /rc/auth/refresh-token` + `identity_id`）。

`school_code` 不存在时返回 HTTP `422` 参数校验错误（`errors.school_code`）。

### 规则

- 数据来源：`schools` 表，按 `school_code` 匹配
- 绑定成功后自动 `firstOrCreate` 一条 `school_profiles` 记录
- 新建资料默认填充 `competent_dept`、`address`（来自学校主表），`status = 2`（审核中）

## 2) 获取当前学校招聘资料

- 接口：`GET /rc/schools/profile`
- 描述：返回当前绑定学校的 `school_profiles` 记录；不存在时自动创建

### 成功响应示例

```json
  "code": 200,
  "data": {
    "profile": {
      "school_code": "4111010001",
      "short_name": "北大",
      "contact_name": "张老师",
      "contact_phone": "13800000000",
      "intro": "国内顶尖高校。",
      "logo": "uploads/rc/school-logo.png",
      "display_logo": "https://example.com/uploads/rc/school-logo.png",
      "education_levels": [3],
      "education_level_labels": ["本科"],
      "main_education_level": 3,
      "main_education_level_label": "本科",
      "allow_company_apply_activity": true,
      "allow_company_cooperate_apply": true,

      "status_label": "正常"
    }
  },
  "meta": {
    "timestamp": 1748865600.1234,

  }

```

### 业务失败

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为校招负责人身份并绑定学校。 |

## 3) 更新当前学校招聘资料

- 接口：`PUT /rc/schools/profile`
- Content-Type：`application/json`
- 描述：更新当前绑定学校的院校展示资料

### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `short_name` | 否 | `nullable`, `string`, `max:100` | 学校简称 |
| `province_code` | 否 | `nullable`, `string`, `max:30` | 省份代码 |
| `city_code` | 否 | `nullable`, `string`, `max:30` | 城市代码 |
| `district_code` | 否 | `nullable`, `string`, `max:30` | 区县代码 |
| `address` | 否 | `nullable`, `string`, `max:200` | 地址 |
| `contact_name` | 否 | `nullable`, `string`, `max:50` | 校方对接总负责人 |
| `contact_phone` | 否 | `nullable`, `string`, `max:20` | 联系电话 |
| `contact_email` | 否 | `nullable`, `email`, `max:100` | 就业办邮箱 |
| `qualification_file` | 否 | `nullable`, `string`, `max:500` | 资质证明 OSS 路径 |
| `competent_dept` | 否 | `nullable`, `string`, `max:50` | 主管部门 |
| `education_levels` | 否 | `nullable`, `array`, `max:10` | 办学层次 |
| `education_levels.*` | 否 | `integer`, Enum | 见 [RcEducationLevel](#rceducationlevel) |
| `main_education_level` | 否 | `nullable`, `integer`, Enum | 主办学层次 |
| `logo` | 否 | `nullable`, `string`, `max:500` | 校徽 Logo OSS 路径 |
| `banner` | 否 | `nullable`, `string`, `max:500` | 首页横幅图 OSS 路径 |
| `allow_company_apply_activity` | 否 | `nullable`, `boolean` | 是否允许企业自主发起进校宣讲申请 |
| `allow_company_cooperate_apply` | 否 | `nullable`, `boolean` | 是否开放校企对接申请入口 |
| `intro` | 否 | `nullable`, `string`, `max:10000` | 院校简介 |
| `remark` | 否 | `nullable`, `string`, `max:2000` | 备注 |

### 请求示例

```json
{
  "short_name": "北大",
  "contact_name": "张老师",
  "contact_phone": "13800000000",
  "intro": "国内顶尖高校。",
  "logo": "uploads/rc/school-logo.png",
  "education_levels": [3],
  "main_education_level": 3,
  "allow_company_apply_activity": false
}
```

### 成功响应

- `data.profile`：更新后的学校资料对象

### 业务失败

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为校招负责人身份并绑定学校。 |

### 规则

- 仅更新请求中出现的字段（部分更新）
- `campus_count`、`department_count`、`cooperate_company_count`、`activity_total`、`status` 不由本接口写入
- 当 `intro`、`logo`、`contact_name`、`contact_phone` 均已填写时，`status` 自动从 `2`（审核中）变为 `1`（正常）

---

## 前端推荐流程

1. `POST /rc/auth/refresh-token`，`identity_type = 3`（校招负责人）
2. `GET /rc/meta/schools` 获取学校字典，记下目标 `value` 作为 `school_code`
3. `POST /rc/schools/bind`（`school_code` + `job_title`）
4. `GET /rc/auth/me` 确认 `has_basic_info`
5. `GET /rc/schools/profile` 查看当前资料
6. 上传 Logo / 横幅 / 资质证明 → `PUT /rc/schools/profile` 完善院校展示资料

| `2` | 专科 |

| `4` | 硕士 |
| `5` | 博士 |
| `6` | 其他 |
