# 收藏

## 说明

- 路由前缀：`/rc`
- 鉴权：均需 `Bearer Token`，并使用 `auth:rc`
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`

### 身份要求

| 能力 | 适用身份 |
|------|----------|
| 收藏 / 取消收藏 / 列表：职位、企业 | 求职者（`identity_type = 1`） |
| 收藏 / 取消收藏 / 列表：简历 | 招聘方（`identity_type = 2`）且已绑定企业 |

### 列表公共规则

- 列表按收藏时间倒序（`favorited_at DESC -> id DESC`）
- 分页结构与 Laravel 标准分页一致：`data`、`total`、`per_page`、`current_page` 等
- 列表项均包含 `is_favorited = true` 与 `favorited_at`（收藏时间）
- Query 参数 `per_page`：默认 15，最大 100

---

## 求职者：我收藏的职位

### 列表

- 接口：`GET /rc/talent/favorites/jobs`
- 描述：返回当前求职者收藏的职位列表

#### 列表项字段

基于 `RcJobResource`，额外包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_favorited` | bool | 固定为 `true` |
| `is_applied` | bool | 是否已投递该职位（不含已撤回） |
| `favorited_at` | string | 收藏时间 |

#### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "current_page": 1,
    "data": [
      {
        "id": 10,
        "title": "Laravel 工程师",
        "company": { "id": 1, "name": "南昌示例科技有限公司" },
        "is_favorited": true,
        "is_applied": false,
        "favorited_at": "2026-06-11T12:00:00.000000Z"
      }
    ],
    "total": 1
  }
}
```

### 收藏 / 取消收藏

| 操作 | 接口 |
|------|------|
| 收藏 | `POST /rc/talent/jobs/{id}/favorite` |
| 取消收藏 | `DELETE /rc/talent/jobs/{id}/favorite` |

详情接口 `GET /rc/talent/jobs/{id}` 登录时返回 `is_favorited`。

## 求职者：我收藏的企业

### 列表

- 接口：`GET /rc/talent/favorites/companies`
- 描述：返回当前求职者收藏的企业列表

#### 列表项字段

基于 `RcCompanyDiscoveryResource`，额外包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_favorited` | bool | 固定为 `true` |
| `favorited_at` | string | 收藏时间 |

#### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "current_page": 1,
    "data": [
      {
        "id": 1,
        "name": "南昌示例科技有限公司",
        "display_name": "示例科技",
        "is_favorited": true,
        "favorited_at": "2026-06-11T12:00:00.000000Z"
      }
    ],
    "total": 1
  }
}
```

### 收藏 / 取消收藏

| 操作 | 接口 |
|------|------|
| 收藏 | `POST /rc/talent/companies/{id}/favorite` |
| 取消收藏 | `DELETE /rc/talent/companies/{id}/favorite` |

企业详情 `GET /rc/talent/companies/{id}` 登录时返回 `is_favorited`；其职位列表项另含 `is_applied`。

## 招聘方：我收藏的简历

### 列表

- 接口：`GET /rc/talent/favorites/resumes`
- 描述：返回当前招聘方用户在**当前绑定企业**下收藏的简历列表

#### 列表项字段

基于 `RcResumePreviewResource`（脱敏），额外包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_favorited` | bool | 固定为 `true` |
| `favorited_at` | string | 收藏时间 |

#### 数据范围

- 仅返回 `status = 正常` 的简历
- 按 `user_id + company_id` 维度隔离；切换绑定企业后列表数据不同

#### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "current_page": 1,
    "data": [
      {
        "id": 8,
        "full_name": "候选人甲",
        "title": "求职简历",
        "is_favorited": true,
        "favorited_at": "2026-06-11T12:00:00.000000Z"
      }
    ],
    "total": 1
  }
}
```

### 收藏 / 取消收藏

| 操作 | 接口 |
|------|------|
| 收藏 | `POST /rc/talent/resumes/{id}/favorite` |
| 取消收藏 | `DELETE /rc/talent/resumes/{id}/favorite` |

简历详情 `GET /rc/talent/resumes/{id}` 返回 `is_favorited`。

---

## 业务失败（通用）

| 场景 | `code` | `message` |
|------|--------|-----------|
| 求职者接口未切换身份 | `422` | 请先切换为求职者身份。 |
| 招聘方接口未绑定企业 | `422` | 请先切换为招聘方身份并绑定企业。 |
| 收藏目标不存在或不可见 | `404` | 职位不存在或已下架。 / 企业不存在或不可查看。 / 简历不存在或不可查看。 |
