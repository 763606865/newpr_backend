# 招聘方校企活动

## 说明

- 路由前缀：`/rc`
- 鉴权：均需 `Bearer Token`，并使用 `auth:rc`
- 控制器：`CompanySchoolActivityController`
- 路径前缀：`/rc/companies/school-activities`
- 适用对象：招聘方身份（`identity_type = 2`），且已绑定企业
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`

> 绑定企业见 [企业.md](./企业.md)。校招侧活动管理见 [校招活动.md](./校招活动.md)。

---

## 接口一览

| 方法 | 路径 | 控制器方法 | 说明 |
|------|------|------------|------|
| `GET` | `/rc/companies/school-activities` | `index` | 我企业参与的活动列表 |
| `GET` | `/rc/companies/school-activities/organized` | `organized` | 我企业主办的活动列表 |
| `GET` | `/rc/companies/school-activities/available` | `available` | 可报名活动列表（活动广场） |
| `POST` | `/rc/companies/school-activities` | `store` | 创建企业主办活动（宣讲会/招聘会） |
| `GET` | `/rc/companies/school-activities/{id}` | `show` | 活动详情 |
| `PUT` | `/rc/companies/school-activities/{id}` | `update` | 更新企业主办活动 |
| `DELETE` | `/rc/companies/school-activities/{id}` | `destroy` | 删除企业主办活动（仅草稿） |
| `POST` | `/rc/companies/school-activities/{id}/publish` | `publish` | 发布企业主办活动 |
| `POST` | `/rc/companies/school-activities/{id}/end` | `end` | 结束企业主办活动 |
| `POST` | `/rc/companies/school-activities/{activityId}/apply` | `apply` | 申请参加院校活动 |
| `GET` | `/rc/companies/school-activities/{activityId}/my-application` | `myApplication` | 本企业单场报名状态 |
| `POST` | `/rc/companies/school-activities/{activityId}/jobs` | `storeJobs` | 提交参会职位 |
| `GET` | `/rc/companies/school-activities/{activityId}/jobs` | `myJobs` | 本企业已提交职位 |

### Headers（全部接口通用）

| Header | 值 |
|--------|-----|
| `Authorization` | `Bearer {access_token}` |
| `Accept` | `application/json` |
| `Content-Type` | `application/json`（`POST` 请求） |

### 分页参数（列表类接口通用）

| 字段 | 是否必填 | 类型 | 说明 |
|------|----------|------|------|
| `per_page` | 否 | int | 每页条数，默认 `15`，范围 `1` ~ `100` |
| `page` | 否 | int | 页码，默认 `1` |

## 4. 申请参加活动

| 项目 | 内容 |
|------|------|
| 方法 | `POST` |
| 路径 | `/rc/companies/school-activities/{activityId}/apply` |
| 控制器 | `CompanySchoolActivityController@apply` |

### 描述

企业自主申请参加活动。写入 `rc_school_activity_companies`，`join_source = 1`，初始 `apply_status = 0`（待审核）。

### 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `activityId` | int | 活动 ID |

### 请求 Body

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `remark` | 否 | `nullable`, `string`, `max:2000` | 申请备注 |

#### 请求示例

```json
{
  "remark": "希望参加本次双选会"
}
```

### 成功响应

```json
{
  "code": 0,
  "data": {
    "application": {
      "id": 60,
      "activity_id": 12,
      "company_id": 8,
      "activity_booth_id": null,
      "join_source": 1,
      "join_source_label": "企业自主申请",
      "apply_status": 0,
      "apply_status_label": "待审核",
      "apply_at": "2026-03-08T14:00:00.000000Z",
      "remark": "希望参加本次双选会"
    }
  },
  "meta": {}
}
```

### 业务规则

- 活动须已发布（`status = 1`）
- 活动须在报名开放期内
- 同一企业同一活动不可重复申请
- 若主办院校 `school_profiles.allow_company_apply_activity = false`，拒绝自主申请

### 业务失败

| HTTP | `message` |
|------|-----------|
| `422` | 请先切换为招聘方身份并绑定企业。 |
| `404` | 活动不存在或未发布。 |
| `422` | 活动未发布，暂不可申请。 |
| `422` | 活动不在报名时间内。 |
| `422` | 您已申请参加该活动。 |
| `422` | 该院校暂未开放企业自主申请。 |

## 6. 提交参会职位

| 项目 | 内容 |
|------|------|
| 方法 | `POST` |
| 路径 | `/rc/companies/school-activities/{activityId}/jobs` |
| 控制器 | `CompanySchoolActivityController@store` |

### 描述

企业报名**已通过**（`apply_status = 1`）后，勾选本企业基础职位提交至活动。

### 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `activityId` | int | 活动 ID |

### 请求 Body

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `job_ids` | 是 | `required`, `array`, `min:1`, `max:50` | 基础职位 ID 列表 |
| `job_ids.*` | 是 | `integer`, 存在于 `rc_jobs.id` | 单条职位 ID |

#### 请求示例

```json
{
  "job_ids": [101, 102, 103]
}
```

### 成功响应

```json
{
  "code": 0,
  "data": {
    "activity_jobs": [
      {
        "id": 30,
        "activity_id": 12,
        "company_id": 8,
        "school_activity_company_id": 56,
        "job_id": 101,
        "audit_status": 0,
        "audit_status_label": "待审核",
        "reject_reason": null,
        "audit_at": null,
        "job": {
          "id": 101,
          "title": "后端工程师",
          "code": "JOB001"
        }
      }
    ]
  },
  "meta": {}
}
```

### 业务规则

- 须先有本企业的活动报名记录
- 企业报名须已通过（`apply_status = 1`）
- `job_ids` 必须全部属于当前绑定企业
- 初始职位审核状态按活动类型区分：
  - 双选会（`type=2`）：`audit_status = 0`（待审核）
  - 招聘会（`type=0`）/宣讲会（`type=1`）：`audit_status = 1`（审核通过）
- 同一活动同一职位重复提交会复用记录；若记录曾被删除后再次提交，会按当前活动类型重置审核状态

### 业务失败

| HTTP | `message` |
|------|-----------|
| `422` | 请先切换为招聘方身份并绑定企业。 |
| `404` | 活动不存在或未发布。 |
| `422` | 请先申请参加活动并通过审批。 |
| `422` | 企业申请尚未通过，无法提交职位。 |
| `422` | 请至少选择一个职位。 |
| `422` | 存在不属于当前企业的职位。 |

| `keyword` | 否 | string | 关键词搜索 |
| `page` / `per_page` | 否 | int | 分页 |

### 规则

- 仅返回 `organizer_type=company` 且 `organizer_id=当前企业 ID` 的活动
- 排序：`sort desc -> updated_at desc -> id desc`
- 响应 `data.data[]` 为 `RcSchoolActivityResource`，含 `schools` 关联院校

## 9) 创建企业主办活动

| 项 | 值 |
|----|-----|
| 方法 | `POST` |
| 路径 | `/rc/companies/school-activities` |
| 控制器 | `CompanySchoolActivityController@store` |

企业主动创建宣讲会或招聘会，并向目标院校发起**申请入校**。创建后为草稿状态。

### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `type` | 是 | `integer`, 枚举 | 仅允许 `0`（招聘会）或 `1`（宣讲会）；**不可创建双选会** |
| `title` | 是 | `string`, `max:255` | 活动标题 |
| `school_codes` | 宣讲会必填 | `array`, `min:1` | 申请入校的目标院校代码；宣讲会（`type=1`）必填，招聘会（`type=0`）可选 |
| `school_codes.*` | 宣讲会必填 | `string`, 存在于 `schools.school_code` | 单个院校代码 |
| `cover_image` | 否 | `string`, `max:500` | 封面图 OSS 路径 |
| `description` | 否 | `string`, `max:10000` | 活动描述 |
| `link_url` | 否 | `url`, `max:500` | 外链 |
| `province_code` / `city_code` / `district_code` | 否 | `string`, `max:32` | 举办地区 |
| `address` | 否 | `string`, `max:200` | 详细地址 |
| `register_start_date` / `register_end_date` | 否 | `date` | 报名时间 |
| `start_time` / `end_time` | 否 | `date` | 举办时间 |
| `contact_name` / `contact_phone` | 否 | `string` | 对接人 |
| `is_hot` | 否 | `boolean` | 是否热门 |
| `sort` | 否 | `integer` | 排序 |
| `files` | 否 | `array` | 附件 |
| `extra` | 否 | `object` | 扩展字段 |
| `remark` | 否 | `string`, `max:2000` | 备注 |

> 企业主办活动**无需**也不支持 `booth_id`（展位模板为院校侧能力）。

### 请求示例

```json
{
  "type": 0,
  "title": "2026 春季线下招聘会",
  "address": "企业总部大厅",
  "start_time": "2026-04-15 14:00:00"
}
```

宣讲会进校示例：

```json
{
  "type": 1,
  "title": "2026 春季进校宣讲会",
  "school_codes": ["4111010001", "4111010002"],
  "city_code": "360100",
  "address": "大学生活动中心",
  "start_time": "2026-04-15 14:00:00",
  "contact_name": "李HR",
  "contact_phone": "13800138000"
}
```

### 成功响应 `data`

| 字段 | 说明 |
|------|------|
| `activity` | 新建活动（`status=0` 草稿，`organizer_type=company`） |

### 业务失败

| HTTP | `message` |
|------|-----------|
| `422` | 请先切换为招聘方身份并绑定企业。 |
| `422` | 企业仅可创建宣讲会或招聘会。 |
| `422` | 宣讲会请选择申请入校的目标院校。 |
| `422` | 存在无效的目标院校代码。 |
| `422` | 院校「{name}」暂未开放企业自主进校申请。 |

## 12) 发布企业主办活动

| 项 | 值 |
|----|-----|
| 方法 | `POST` |
| 路径 | `/rc/companies/school-activities/{id}/publish` |
| 控制器 | `CompanySchoolActivityController@publish` |

### 规则

- 宣讲会（`type=1`）发布前须关联至少一所目标院校（`school_codes`）
- 招聘会（`type=0`）可不关联院校（企业线下自办）；若填写 `school_codes` 则表示进校举办，须目标院校 `allow_company_apply_activity = true`，后续由院校审批及分配场地
- 无需配置展位模板（与院校主办双选会不同）
- 发布成功后自动写入本企业参会记录（`join_source=2` 企业主办，`apply_status=1` 通过）
- 活动出现在 [我企业参与的活动列表](#1-我企业参与的活动列表) 中，`is_organizer=true`

### 业务失败

| HTTP | `message` |
|------|-----------|
| `422` | 请先选择申请入校的目标院校。 |
| `422` | 活动已发布，无需重复操作。 |

## 典型业务流程

### A. 参加院校活动（原有流程）

```text
1. GET  /rc/companies/school-activities/available     浏览可报名活动
2. GET  /rc/companies/school-activities/{id}          查看活动详情（可选）
3. POST /rc/companies/school-activities/{id}/apply    申请参加
4. GET  /rc/companies/school-activities               查看我的活动（含待审核）
5. GET  /rc/companies/school-activities/{id}/my-application   查看审批结果
6. POST /rc/companies/school-activities/{id}/jobs     提交参会职位（须已通过）
7. GET  /rc/companies/school-activities/{id}/jobs     查看职位审核状态
```

### B. 企业主动进校（新增）

```text
1. POST /rc/companies/school-activities                创建宣讲会/招聘会草稿（宣讲会需 school_codes）
2. PUT  /rc/companies/school-activities/{id}           完善活动信息（可选）
3. POST /rc/companies/school-activities/{id}/publish   发布并向目标院校申请入校
4. GET  /rc/companies/school-activities/organized     管理我主办的活动
5. GET  /rc/companies/school-activities                 查看参与记录（is_organizer=true）
6. POST /rc/companies/school-activities/{id}/end        活动结束后归档
```
