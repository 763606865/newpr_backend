# 用户

## 说明

- 路由前缀：`/rc`
- 鉴权：均需 `Bearer Token`，并使用 `auth:rc`
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`
- 手机号格式：`^1\d{10}$`

---

## 1) 手机号检索

- 接口：`GET /rc/users/phone/lookup`
- 描述：检查手机号是否已存在，以及是否可用于当前登录用户修改手机号

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `phone` | 是 | `string`, `regex:/^1\d{10}$/` | 待检索手机号 |

### 请求示例

```bash
curl -X GET "https://example.com/rc/users/phone/lookup?phone=13800138001" \
  -H "Authorization: Bearer <access-token>"
```

### 成功响应示例

手机号已被其他用户使用：

```json
{
  "code": 200,
  "data": {
    "phone": "13800138001",
    "exists": true,
    "available": false,
    "is_current_user": false
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

手机号未被使用：

```json
{
  "code": 200,
  "data": {
    "phone": "13800138002",
    "exists": false,
    "available": true,
    "is_current_user": false
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 响应字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `phone` | string | 检索手机号 |
| `exists` | bool | 是否存在用户使用该手机号 |
| `available` | bool | 是否可用于当前用户修改手机号 |
| `is_current_user` | bool | 该手机号是否属于当前登录用户 |

---

## 2) 发送修改手机号验证码

- 接口：`POST /rc/users/phone/verification-code`
- 描述：向目标手机号发送修改手机号验证码

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `phone` | 是 | `string`, `regex:/^1\d{10}$/` | 新手机号 |

### 请求示例

```json
{
  "phone": "13800138002"
}
```

```bash
curl -X POST "https://example.com/rc/users/phone/verification-code" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800138002"}'
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {},
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

手机号已被其他用户使用：

```json
{
  "code": 422,
  "message": "手机号已被其他用户使用。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

验证码发送过于频繁：

```json
{
  "code": 429,
  "message": "验证码发送过于频繁，请稍后再试。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

## 3) 修改手机号

- 接口：`PUT /rc/users/phone`
- 描述：校验短信验证码并修改当前登录用户手机号

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `phone` | 是 | `string`, `regex:/^1\d{10}$/` | 新手机号 |
| `code` | 是 | `digits:6` | 6 位短信验证码 |

### 请求示例

```json
{
  "phone": "13800138002",
  "code": "123456"
}
```

```bash
curl -X PUT "https://example.com/rc/users/phone" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800138002","code":"123456"}'
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "phone": "13800138002"
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

新手机号与当前手机号相同：

```json
{
  "code": 422,
  "message": "新手机号不能与当前手机号相同。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

手机号已被其他用户使用：

```json
{
  "code": 422,
  "message": "手机号已被其他用户使用。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

验证码错误或已失效：

```json
{
  "code": 422,
  "message": "验证码错误或已失效。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```
