# 用户

## 说明

- 路由前缀：`/rc`
- 鉴权：均需 `Bearer Token`，并使用 `auth:rc`
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`
- 手机号格式：`^1\d{10}$`

---

## 1) 手机号检索

- 接口：`GET /rc/users/phone/lookup`
- 描述：检查手机号是否已存在，以及是否可用于当前登录用户修改手机号

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `phone` | 是 | `string`, `regex:/^1\d{10}$/` | 待检索手机号 |

### 请求示例

```bash
curl -X GET "https://example.com/rc/users/phone/lookup?phone=13800138001" \
  -H "Authorization: Bearer <access-token>"
```

### 成功响应示例

手机号已被其他用户使用：

```json
{
  "code": 200,
  "data": {
    "phone": "13800138001",
    "exists": true,
    "available": false,
    "is_current_user": false
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

手机号未被使用：

```json
{
  "code": 200,
  "data": {
    "phone": "13800138002",
    "exists": false,
    "available": true,
    "is_current_user": false
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 响应字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `phone` | string | 检索手机号 |
| `exists` | bool | 是否存在用户使用该手机号 |
| `available` | bool | 是否可用于当前用户修改手机号 |
| `is_current_user` | bool | 该手机号是否属于当前登录用户 |

## 2) 发送修改手机号验证码

- 接口：`POST /rc/users/phone/verification-code`
- 描述：向目标手机号发送修改手机号验证码

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `phone` | 是 | `string`, `regex:/^1\d{10}$/` | 新手机号 |

### 请求示例

```json
{
  "phone": "13800138002"
}
```

```bash
curl -X POST "https://example.com/rc/users/phone/verification-code" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800138002"}'
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {},
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

手机号已被其他用户使用：

```json
{
  "code": 422,
  "message": "手机号已被其他用户使用。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

验证码发送过于频繁：

```json
{
  "code": 429,
  "message": "验证码发送过于频繁，请稍后再试。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

## 3) 修改手机号

- 接口：`PUT /rc/users/phone`
- 描述：校验短信验证码并修改当前登录用户手机号

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `phone` | 是 | `string`, `regex:/^1\d{10}$/` | 新手机号 |
| `code` | 是 | `digits:6` | 6 位短信验证码 |

### 请求示例

```json
{
  "phone": "13800138002",
  "code": "123456"
}
```

```bash
curl -X PUT "https://example.com/rc/users/phone" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800138002","code":"123456"}'
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "phone": "13800138002"
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

新手机号与当前手机号相同：

```json
{
  "code": 422,
  "message": "新手机号不能与当前手机号相同。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

手机号已被其他用户使用：

```json
{
  "code": 422,
  "message": "手机号已被其他用户使用。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

验证码错误或已失效：

```json
{
  "code": 422,
  "message": "验证码错误或已失效。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

## 4) 求职者企业黑名单列表

- 接口：`GET /rc/users/company-blacklists`
- 描述：返回当前登录求职者维护的企业黑名单。该黑名单仅用于屏蔽企业推荐/曝光，不代表平台对企业的违规封禁。
- 身份要求：求职者身份

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `page` | 否 | `integer`, `min:1` | 页码 |
| `per_page` | 否 | `integer`, `min:1`, `max:100` | 每页条数，默认 `15` |
| `keyword` | 否 | `string` | 企业名称或统一社会信用代码关键词 |

### 请求示例

```bash
curl -X GET "https://example.com/rc/users/company-blacklists?keyword=示例&per_page=15" \
  -H "Authorization: Bearer <access-token>"
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "current_page": 1,
    "data": [
      {
        "id": 1,
        "user_id": 10,
        "company_id": 100,
        "remark": "老东家",
        "company": {
          "id": 100,
          "name": "南昌示例科技有限公司",
          "credit_code": "91360100MA0000000X",
          "legal_person": "张三",
          "contact_phone": "13800138000",
          "address": "江西省南昌市",
          "status": "enabled",
          "created_at": "2026-07-03 10:00:00",
          "updated_at": "2026-07-03 10:00:00"
        },
        "created_at": "2026-07-03 10:00:00",
        "updated_at": "2026-07-03 10:00:00"
      }
    ],
    "per_page": 15,
    "total": 1
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

当前身份不是求职者：

```json
{
  "code": 422,
  "message": "请先切换为求职者身份。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

## 5) 新增企业黑名单

- 接口：`POST /rc/users/company-blacklists`
- 描述：将企业加入当前登录求职者的企业黑名单。同一求职者不能重复添加同一家企业。
- 身份要求：求职者身份

### 请求参数

| 字段 | 是否必填 | 类型/规则 | 说明 |
|------|----------|-----------|------|
| `company_id` | 是 | `exists:companies,id` | 企业 ID，企业不能是软删除状态 |
| `remark` | 否 | `nullable`, `string`, `max:255` | 备注 |

### 请求示例

```json
{
  "company_id": 100,
  "remark": "老东家"
}
```

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "blacklist": {
      "id": 1,
      "user_id": 10,
      "company_id": 100,
      "remark": "老东家",
      "company": {
        "id": 100,
        "name": "南昌示例科技有限公司",
        "credit_code": "91360100MA0000000X"
      },
      "created_at": "2026-07-03 10:00:00",
      "updated_at": "2026-07-03 10:00:00"
    }
  },
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

重复添加：

```json
{
  "code": 422,
  "message": "企业已在黑名单中。",
  "meta": {
    "timestamp": 1782960000.1234,
    "response_time": 0.0123
  }
}
```
