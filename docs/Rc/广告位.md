# 广告位

## 说明

- 路由前缀：`/cms`
- 鉴权：无
- 中间件：不在 `optional-rc-auth` 分组内，可匿名访问
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 对应实现：`app/Http/Controllers/AdController.php@index`

该接口用于前端按广告位编码获取广告位信息及其可展示广告列表。

---

## 公共数据结构

### 广告位对象（`ad_slot`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 广告位 ID |
| `name` | string | 广告位名称 |
| `code` | string | 广告位编码 |
| `type` | int | 广告位类型，见 [CmsAdType](#cmsadtype) |
| `type_label` | string\|null | 广告位类型中文 |
| `width` | int\|null | 建议宽度 |
| `height` | int\|null | 建议高度 |
| `remark` | string\|null | 备注 |

### 广告对象（`ads[]`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 广告 ID |
| `slot_id` | int | 广告位 ID |
| `city_code` | string\|null | 城市编码；为空表示全站可用 |
| `title` | string | 广告标题 |
| `type` | int | 广告类型，见 [CmsAdType](#cmsadtype) |
| `type_label` | string\|null | 广告类型中文 |
| `image` | string\|null | 图片 OSS 路径，返回时会去除开头 `/` |
| `image_url` | string\|null | 图片可访问 URL；OSS 私有桶时可能是临时 URL |
| `text_content` | string\|null | 文本内容 |
| `code_content` | string\|null | 代码内容 |
| `link_url` | string\|null | 跳转地址 |
| `start_at` | string\|null | 生效开始时间 |
| `end_at` | string\|null | 生效结束时间 |
| `sort` | int | 排序值 |
| `extra` | object\|null | 扩展字段 |

## 1) 获取广告位广告

- 接口：`GET /cms/ads`
- 路由名称：`ad.index`
- 描述：按广告位编码获取启用广告位及其启用广告列表

### Query 参数

| 字段 | 类型/规则 | 是否必填 | 说明 |
|------|-----------|----------|------|
| `code` | string, max:64 | 是 | 广告位编码，对应 `cms_ad_slots.code` |
| `city_code` | string, max:32 | 否 | 城市编码；传入后返回该城市广告和全站广告 |

### 请求示例

```http
GET /cms/ads?code=home.sidebar
```

```http
GET /cms/ads?code=city.home&city_code=360100
```

### 返回规则

- 广告位必须启用：`cms_ad_slots.status = 1`
- 广告必须启用：`cms_ads.status = 1`
- 按广告位编码精确匹配：`cms_ad_slots.code = code`
- 传入 `city_code` 时，广告列表包含：
  - `cms_ads.city_code = city_code`
  - `cms_ads.city_code IS NULL`
- 未传 `city_code` 时，不按城市过滤
- 广告排序：`sort asc, id asc`
- 广告位不存在或已停用时返回 `404`

> 当前实现不会按 `start_at` / `end_at` 过滤有效期；如需仅返回有效期内广告，需要后端额外加 `active()` 类过滤。
