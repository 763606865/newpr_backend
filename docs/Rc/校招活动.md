# 校招活动（展位 / 活动 / 企业报名）

## 说明

- 路由前缀：`/rc`
  - 鉴权：均需 `Bearer Token`，并使用 `auth:rc`
  - 适用对象：
    - **校招负责人**（`identity_type = 3`）：维护展位、创建活动、邀约/审批企业、审批职位
    - **招聘方**（`identity_type = 2`）：申请参加活动、提交参会职位
  - 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
  - 业务错误：`error()`，结构为 `code` + `message` + `meta`

> 校招负责人接口需先绑定学校（见 [学校.md](./学校.md)）；招聘方接口需先绑定企业（见 [企业.md](./企业.md)）。

校招侧路由统一挂载在 `/rc/schools` 下：

- `/rc/schools/profile`、`/rc/schools/bind` — 学校资料与绑定
  - `/rc/schools/booths` — 展位模板与展区配置
  - `/rc/schools/activities` — 校招负责人活动管理、企业/职位审批

招聘方侧活动接口统一挂载在 `/rc/companies/school-activities` 下，完整文档见 [招聘方校企活动.md](./招聘方校企活动.md)。

## 二、校招负责人 - 展区配置

展区挂载在展位模板下；创建/更新时服务端自动计算 `total_booth_count`，并回填所属展位的 `total_booth_count`。

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/rc/schools/booths/{boothId}/areas` | 展区列表 |
| `POST` | `/rc/schools/booths/{boothId}/areas` | 创建展区 |
| `GET` | `/rc/schools/booths/{boothId}/areas/{id}` | 展区详情 |
| `PUT` | `/rc/schools/booths/{boothId}/areas/{id}` | 更新展区 |
| `DELETE` | `/rc/schools/booths/{boothId}/areas/{id}` | 删除展区 |

#### 创建展区请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `name` | 是 | `required`, `string`, `max:100` | 展区名称 |
| `start_no` | 是 | `required`, `integer`, `min:1` | 展位起始号 |
| `end_no` | 是 | `required`, `integer`, `gte:start_no` | 展位结束号 |
| `code` | 否 | `nullable`, `string`, `max:20` | 展区编码 |
| `map_image` | 否 | `nullable`, `string`, `max:500` | 分区平面图 |
| `sort` | 否 | `nullable`, `integer`, `min:0` | 排序 |

## 三、校招负责人 - 活动管理

### 1) 活动列表

- 接口：`GET /rc/schools/activities`
  - 描述：仅返回当前绑定学校主办的活动（`organizer_type=school`，见 [RcSchoolActivityOrganizerType](#rcschoolactivityorganizertype)）

#### Query

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `status` | 否 | 活动状态 |
| `type` | 否 | 活动类型 |
| `keyword` | 否 | 标题模糊搜索 |

---

### 2) 创建活动

- 接口：`POST /rc/schools/activities`
  - 描述：创建草稿活动，写入 `rc_school_activities.booth_id`，并自动写入 `rc_school_activity_schools` 关联当前学校；**同时根据所选展位模板批量生成 `rc_school_activity_booths` 记录**

#### 请求参数（节选）

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `title` | 是 | `required`, `string`, `max:255` | 活动标题 |
| `booth_id` | 是 | `exists:rc_school_booths,id` | 展位模板 ID（写入活动表，并批量生成活动展位） |

#### 请求示例

```json
{
  "type": 2,
  "title": "2026 春季双选会",
  "booth_id": 12,
  "description": "面向2026届毕业生",
  "register_start_date": "2026-03-01 00:00:00",
  "register_end_date": "2026-03-31 23:59:59",
  "start_time": "2026-04-10 09:00:00",
  "end_time": "2026-04-10 17:00:00"
}
```

#### 展位生成规则

- 将 `booth_id` 持久化到 `rc_school_activities.booth_id`
- 读取该模板下的全部展区
- 按每个展区的 `start_no` ~ `end_no` 逐号生成活动展位
- 展位编号格式：`{展区 code 或 name}-{两位序号}`，如 `A-01`

---

### 3) 活动详情 / 更新 / 删除

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/rc/schools/activities/{id}` | 校招负责人查看本校活动（含 `activity_booths` 列表） |
| `PUT` | `/rc/schools/activities/{id}` | 更新（已结束不可编辑） |
| `DELETE` | `/rc/schools/activities/{id}` | 删除（仅草稿可删） |

#### 活动详情响应 `data.activity`（节选）

| 字段 | 说明 |
|------|------|
| `booth_id` | 采用的展位模板 ID |
| `booth` | 展位模板摘要（含 `areas` 展区列表） |
| `activity_booths_count` | 活动展位数 |
| `activity_booths` | **活动展位列表**，按 `booth_no` 排序；邀约企业时传其中空闲展位的 `id` 作为 `activity_booth_id` |

`activity_booths` 单项含 `booth_no`、`company_id`；已分配时附带 `company`（`id`、`name`）。

#### 更新展位配置

- 请求体可传 `booth_id` 重新选择展位模板，服务端会**更新活动表 `booth_id`、删除旧活动展位并重新批量生成**
- **限制**：仅**草稿**且**尚无企业报名记录**时可修改；活动已发布或已有邀约/申请企业时返回 `422`

---

### 4) 发布 / 结束活动

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/rc/schools/activities/{id}/publish` | 草稿 → 已发布（须已配置活动展位） |
| `POST` | `/rc/schools/activities/{id}/end` | 任意状态 → 已结束 |

## 四、校招负责人 - 企业邀约与审批

### 1) 企业报名列表

- 接口：`GET /rc/schools/activities/{activityId}/company-applications`

#### Query

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `apply_status` | 否 | 申请状态 |
| `join_source` | 否 | 报名来源 |

---

### 2) 邀约企业

- 接口：`POST /rc/schools/activities/{activityId}/company-invitations`
  - 描述：院校后台直接邀约已注册企业，`join_source=0`，默认 `apply_status=1`（已通过）

#### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `company_id` | 是 | `exists:companies,id` | 企业 ID（可通过 `GET /rc/companies/lookup` 检索） |
| `activity_booth_id` | 否 | `exists:rc_school_activity_booths,id` | 预分配活动展位（传活动详情中空闲展位的 `id`） |
| `remark` | 否 | `string`, `max:2000` | 备注 |

#### 通知

邀约成功后，向该企业下**全部已绑定招聘方身份**的用户写入站内通知（`SchoolActivityCompanyInvited`），详见 [通知.md](./通知.md)。

#### 企业检索

邀约前可通过 `GET /rc/companies/lookup` 检索企业：

- 按统一社会信用代码：`?credit_code=91360100MA0000000X`，返回 `exists` + `company`
- 按企业名称模糊搜索：`?name=示例科技`，返回 `companies` 列表

#### 线索企业（未注册）

若企业尚未在系统中注册，校招负责人可使用活动详情中的 `invite_code` 生成邀请二维码/链接，由企业自行填写基础信息加入活动（见下方「公开邀请页」）。

活动资源 `activity.invite_code` 由活动 ID 加密生成，可用于：

- 邀请页详情：`GET /rc/activities/invite/{inviteCode}`
- 提交企业信息：`POST /rc/activities/invite/{inviteCode}`

---

### 3) 审批企业申请

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/rc/schools/activities/{activityId}/company-applications/{id}/approve` | 通过待审核申请 |

#### 请求参数（可选）

| 字段 | 说明 |
|------|------|
| `activity_booth_id` | 通过后分配的活动展位 |
| `remark` | 审核意见 |

## 七、公开邀请页（无需认证）

用于院校向未注册企业发送二维码/链接，企业填写基础信息后加入活动。

### 1) 邀请页活动详情

- 接口：`GET /rc/activities/invite/{inviteCode}`
- 描述：根据活动 `invite_code` 返回邀请文案与活动详情

#### 成功响应 `data`

| 字段 | 说明 |
|------|------|
| `inviter_name` | 邀请方名称（学校名称） |
| `invitation_message` | 邀请文案，如「北京大学邀请你参加2026 春季双选会」 |
| `activity` | 活动详情（含 `invite_code`） |

---

### 2) 提交企业信息并加入活动

- 接口：`POST /rc/activities/invite/{inviteCode}`
- 描述：填写企业基础信息；若企业不存在则自动写入 `companies` 表，并以院校邀约方式加入活动（`join_source=0`，`apply_status=1`）

#### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `name` | 是 | `string`, `max:255` | 企业名称 |
| `credit_code` | 是 | `string`, `size:18` | 统一社会信用代码 |
| `contact_phone` | 是 | `string`, `max:255` | 联系电话 |

#### 成功响应 `data`

| 字段 | 说明 |
|------|------|
| `company` | 新建或已存在的企业 |
| `application` | 活动企业关联记录 |

## 前端推荐流程

### 校招负责人

1. 绑定学校 → 维护展位模板与展区
   2. 创建活动（草稿）→ 选择展位模板并自动生成活动展位 → 编辑完善 → 发布
   3. 邀约企业 / 审批企业自主申请
   4. 对未注册线索企业生成 `invite_code` 二维码，引导填写企业信息
   5. 审批企业提交的参会职位

### 招聘方

1. 浏览 [可报名活动列表](./招聘方校企活动.md#2-可报名活动列表)
   2. [活动详情](./招聘方校企活动.md#3-活动详情)（可选）
   3. [申请参加](./招聘方校企活动.md#4-申请参加活动)
   4. [我的活动列表](./招聘方校企活动.md#1-我企业参与的活动列表)
   5. [提交参会职位](./招聘方校企活动.md#6-提交参会职位)
