# 校招资讯

校招负责人在 RC 端管理本校校园资讯（`cms_articles`），发布后在 CMS 门户 `/cms/articles` 公开展示。

> 门户端公开接口见 [校园资讯.md](../Cms/校园资讯.md)。

---

## 鉴权

- 全部接口需 `auth:rc`
- 当前身份须为**校招负责人**且已绑定学校
- 仅能操作 `school_code` 与当前绑定学校一致的资讯

---

## 发布状态枚举（`status`）

| value | label |
|-------|-------|
| `1` | 草稿 |
| `2` | 已发布 |
| `3` | 下线 |

---

## 正文类型枚举（`content_type`）

| value | label |
|-------|-------|
| `1` | HTML |
| `2` | Markdown |

---

## 1) 资讯列表

- 接口: `GET /rc/schools/articles`
- Query 参数:
  - `status`（可选，int）：发布状态
  - `category_id`（可选，int）：分类 ID
  - `keyword`（可选，string，最大 100 字）：标题/摘要模糊搜索
  - `page`（可选，int），默认 `1`
  - `per_page`（可选，int），默认 `15`，最大 `100`

### 返回 `data`

分页结构，`data.data[]` 为 `article` 资源列表（含 `status`、正文等管理字段）。

---

## 2) 资讯详情

- 接口: `GET /rc/schools/articles/{id}`

### 返回 `data.article`

包含分类、标签、正文、SEO 等完整字段。

---

## 3) 创建资讯

- 接口: `POST /rc/schools/articles`
- 说明: 创建草稿；自动写入当前绑定学校的 `school_code`

### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `title` | 是 | `string`, `max:255` | 标题 |
| `category_id` | 否 | `exists:cms_article_categories,id` | 分类 |
| `city_code` | 否 | `string`, `max:32` | 城市编码 |
| `sub_title` | 否 | `string`, `max:255` | 副标题 |
| `slug` | 否 | `string`, `max:191` | 别名 |
| `cover` | 否 | `string`, `max:500` | 封面 OSS 路径 |
| `summary` | 否 | `string`, `max:1000` | 摘要 |
| `content` | 否 | `string` | 正文 |
| `content_type` | 否 | `1\|2` | 正文类型，默认 HTML |
| `author` | 否 | `string`, `max:255` | 作者 |
| `source_name` | 否 | `string`, `max:255` | 来源名称 |
| `source_url` | 否 | `url`, `max:500` | 来源链接 |
| `is_top` | 否 | `boolean` | 置顶 |
| `is_recommend` | 否 | `boolean` | 推荐 |
| `seo_keywords` | 否 | `string`, `max:255` | SEO 关键词 |
| `seo_description` | 否 | `string`, `max:1000` | SEO 描述 |
| `tag_ids` | 否 | `array` | 文章标签 ID 列表 |
| `extra` | 否 | `array` | 扩展字段 |

---

## 4) 更新资讯

- 接口: `PUT /rc/schools/articles/{id}`
- 限制: 仅**草稿**或**下线**状态可编辑；已发布须先下线

参数同创建（`title` 非必填）。

---

## 5) 删除资讯

- 接口: `DELETE /rc/schools/articles/{id}`
- 限制: 仅**草稿**可删除（软删除）

---

## 6) 发布资讯

- 接口: `POST /rc/schools/articles/{id}/publish`
- 说明: 草稿/下线 → 已发布；须已填写标题与正文
- 首次发布自动写入 `published_at`

---

## 7) 下线资讯

- 接口: `POST /rc/schools/articles/{id}/offline`
- 说明: 已发布 → 下线；下线后 CMS 端不可见，可再次编辑后发布

---

## 接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/rc/schools/articles` | 本校资讯列表 |
| `GET` | `/rc/schools/articles/{id}` | 资讯详情 |
| `POST` | `/rc/schools/articles` | 创建资讯 |
| `PUT` | `/rc/schools/articles/{id}` | 更新资讯 |
| `DELETE` | `/rc/schools/articles/{id}` | 删除草稿 |
| `POST` | `/rc/schools/articles/{id}/publish` | 发布 |
| `POST` | `/rc/schools/articles/{id}/offline` | 下线 |

---

## 推荐流程

1. 校招负责人绑定学校
2. 创建资讯草稿 → 填写标题、摘要、正文
3. 发布 → CMS 门户 `/cms/articles` 可见
4. 需要修改时先下线 → 编辑 → 重新发布

平台级资讯（无 `school_code`）仍由 Filament CMS 后台维护。
