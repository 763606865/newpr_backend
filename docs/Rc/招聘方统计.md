# 招聘方统计接口

## 概览
- 路径：GET /rc/users/recruiter/stats
- 权限：已登录用户，并已切换/绑定为招聘方身份（Recruiter）。
- 说明：返回企业招聘相关的统计数据（当前在招职位、收到的简历、未读简历、职位刷新次数、企业会员有效期、发布职位总数）。若某些数据暂未实现，会返回占位值（0 或 null）。

---

## 请求示例

curl 示例：

```bash
curl -s -H "Authorization: Bearer {ACCESS_TOKEN}" \
  -H "Accept: application/json" \
  "https://api.example.com/rc/users/recruiter/stats"
```

请求头：
- Authorization: Bearer {token}
- Accept: application/json

---

## 成功响应（200）

字段说明：
- current_open_jobs (int) — 当前在招职位数（已发布且未过期）
- received_resumes (int) — 已收到的投递总数（Application 表总数）
- unread_resumes (int) — 未读简历数（当前实现占位 0，后续接入 Application/通知系统）
- job_refresh_count (int) — 职位刷新次数（当前占位 0，后续从操作日志统计）
- membership_expires_at (string|null) — 企业会员到期时间，格式 YYYY-MM-DD HH:MM:SS，若无则 null
- posted_jobs_count (int) — 企业历史发布职位总数

示例：

```json
{
  "current_open_jobs": 5,
  "received_resumes": 42,
  "unread_resumes": 0,
  "job_refresh_count": 0,
  "membership_expires_at": "2026-12-31 23:59:59",
  "posted_jobs_count": 128
}
```

---

## 失败响应（示例）

1) 非招聘方身份或未切换身份（HTTP 422）

```json
{
  "message": "请先切换为招聘方身份。"
}
```

2) 未绑定企业（HTTP 422）

```json
{
  "message": "未绑定企业信息。"
}
```
