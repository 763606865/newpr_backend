# 招聘方 - 面试日程列表

对应实现：`app/Rc/Controllers/CompanyInterviewController.php@index`

- 方法：`GET`
- URI：`/rc/companies/interviews`
- 鉴权：是（需切换到招聘方身份并绑定企业）

## 请求参数（Query）

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| per_page | integer | 否 | 每页数量，默认 15 |
| status | integer | 否 | 面试状态（枚举值） |
| job_id | integer | 否 | 按职位过滤 |
| interview_at_from | string (ISO8601) | 否 | 面试开始时间范围（含） |
| interview_at_to | string (ISO8601) | 否 | 面试结束时间范围（含） |

## 示例请求

```
GET /rc/companies/interviews?interview_at_from=2026-07-01T00:00:00Z&interview_at_to=2026-07-31T23:59:59Z
Authorization: Bearer {token}
```

## 错误示例（未绑定企业）

```json
{
  "code": 422,
  "message": "请先切换为招聘方身份并绑定企业。"
}
```
