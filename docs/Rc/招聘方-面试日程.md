# 招聘方 - 面试日程列表

对应实现：`app/Rc/Controllers/CompanyInterviewController.php@index`

- 方法：`GET`
- URI：`/rc/companies/interviews`
- 鉴权：是，需登录 `rc` 并切换到招聘方身份
- 身份要求：当前招聘方身份必须绑定企业（`organization_type = company` 且 `organization_id` 有值）
- 数据范围：只返回当前招聘方绑定企业下的面试记录
- 排序规则：按 `interview_at` 倒序，再按 `id` 倒序

## 业务说明

用于招聘方在后台或移动端查看本企业的面试日程。接口返回的是分页数据，每条记录包含：

- 面试基础信息：时间、时长、方式、面试官、地点、会议链接、备注、状态
- 关联投递信息：职位、简历/候选人摘要、投递状态等

> 注意：该接口只查询面试日程，不负责创建、接受或拒绝面试邀请。邀请面试请使用 `POST /rc/companies/applications/{id}/invite-interview`。

## 请求参数（Query）

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `per_page` | integer | 否 | 每页数量，默认由后端分页逻辑决定，常见默认值为 `15` |
| `page` | integer | 否 | 页码，从 `1` 开始 |
| `status` | integer | 否 | 面试状态。见 [面试状态枚举](#面试状态枚举-rcinterviewstatus) |
| `job_id` | integer | 否 | 按职位 ID 过滤，只返回该职位关联投递下的面试记录 |
| `interview_at_from` | string | 否 | 面试开始时间范围，包含该时间。支持 Laravel 可解析的日期时间字符串 |
| `interview_at_to` | string | 否 | 面试结束时间范围，包含该时间。支持 Laravel 可解析的日期时间字符串 |

## 请求示例

```http
GET /rc/companies/interviews?interview_at_from=2026-07-01T00:00:00Z&interview_at_to=2026-07-31T23:59:59Z&status=1&page=1&per_page=15
Authorization: Bearer {token}
```

## 响应结构

该接口返回分页对象。`data.data` 是面试日程列表，`data.current_page`、`data.per_page`、`data.total` 等为分页信息。

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "current_page": 1,
    "data": [],
    "first_page_url": "http://example.com/rc/companies/interviews?page=1",
    "from": 1,
    "last_page": 1,
    "last_page_url": "http://example.com/rc/companies/interviews?page=1",
    "links": [],
    "next_page_url": null,
    "path": "http://example.com/rc/companies/interviews",
    "per_page": 15,
    "prev_page_url": null,
    "to": 1,
    "total": 1
  }
}
```

### 分页字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | integer | 业务状态码，成功为 `200` |
| `message` | string | 响应消息，成功通常为 `success` |
| `data.current_page` | integer | 当前页码 |
| `data.data` | array | 当前页的面试日程列表 |
| `data.from` | integer\|null | 当前页第一条数据在总列表中的序号；无数据时为 `null` |
| `data.to` | integer\|null | 当前页最后一条数据在总列表中的序号；无数据时为 `null` |
| `data.per_page` | integer | 每页数量 |
| `data.total` | integer | 符合条件的总记录数 |
| `data.last_page` | integer | 最后一页页码 |
| `data.path` | string | 当前分页接口基础路径 |
| `data.first_page_url` | string | 第一页 URL |
| `data.last_page_url` | string | 最后一页 URL |
| `data.next_page_url` | string\|null | 下一页 URL；没有下一页时为 `null` |
| `data.prev_page_url` | string\|null | 上一页 URL；没有上一页时为 `null` |
| `data.links` | array | Laravel 分页链接数据，前端一般可忽略 |

## 面试记录字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 面试记录 ID，对应 `rc_interviews.id` |
| `interview_at` | string\|null | 面试时间，ISO8601 格式；可能为空 |
| `duration_mins` | integer\|null | 面试时长，单位：分钟 |
| `mode` | integer\|null | 面试方式枚举值，见 [面试方式枚举](#面试方式枚举-rcinterviewmode) |
| `mode_label` | string\|null | 面试方式中文，例如 `线上`、`线下`、`电话` |
| `interviewer_name` | string\|null | 面试官姓名 |
| `location` | string\|null | 面试地点或补充说明。线下面试可填写地址，线上面试可填写会议号 |
| `meeting_url` | string\|null | 线上会议链接 |
| `note` | string\|null | 面试备注，例如注意事项、携带材料等 |
| `status` | integer\|null | 面试状态枚举值，见 [面试状态枚举](#面试状态枚举-rcinterviewstatus) |
| `status_label` | string\|null | 面试状态中文，例如 `待候选人确认`、`已安排` |
| `application` | object\|null | 关联投递记录。正常情况下有值；若关联投递被删除或未加载则可能为 `null` |

## application 字段说明

`application` 使用投递资源结构，常见字段如下。具体完整结构以 `docs/Rc/投递.md` 为准。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `application.id` | integer | 投递记录 ID，对应 `rc_applications.id` |
| `application.company_id` | integer | 企业 ID |
| `application.job_id` | integer | 职位 ID |
| `application.resume_id` | integer\|null | 简历 ID |
| `application.candidate_user_id` | integer | 候选人用户 ID |
| `application.current_stage_id` | integer\|null | 当前招聘阶段 ID，未使用时为 `null` |
| `application.source_type` | integer\|null | 投递来源枚举值 |
| `application.source_type_label` | string\|null | 投递来源中文 |
| `application.status` | integer\|null | 投递状态枚举值 |
| `application.status_label` | string\|null | 投递状态中文 |
| `application.applied_at` | string\|null | 投递时间 |
| `application.withdrawn_at` | string\|null | 撤回时间；未撤回时为 `null` |
| `application.created_at` | string\|null | 创建时间 |
| `application.updated_at` | string\|null | 更新时间 |
| `application.job` | object\|null | 职位信息。当前接口已加载 `application.job` |
| `application.resume` | object\|null | 简历信息。当前接口已加载 `application.resume` |
| `application.candidate` | object\|null | 候选人摘要。当简历关系不存在但存在 `resume_snapshot` 时可能返回 |
| `application.pending_interview_invitation` | object\|null | 待候选人确认的面试邀请；当前列表中的面试若不是待确认状态，该字段可能不存在 |
| `application.offer` | object\|null | 有效 Offer 信息；存在已发送或已接受 Offer 时可能返回 |

## 面试方式枚举 RcInterviewMode

| 值 | 中文 | 说明 |
| --- | --- | --- |
| `1` | 线上 | 视频会议、在线会议等远程面试 |
| `2` | 线下 | 到公司或指定地点现场面试 |
| `3` | 电话 | 电话沟通面试 |

## 面试状态枚举 RcInterviewStatus

| 值 | 中文 | 说明 |
| --- | --- | --- |
| `0` | 待安排 | 面试记录已创建，但尚未明确安排 |
| `1` | 已安排 | 面试已确认并安排，通常表示候选人已接受邀请 |
| `2` | 已完成 | 面试已结束 |
| `3` | 已取消 | 面试取消，可能是候选人拒绝、招聘方取消或邀请作废 |
| `4` | 待候选人确认 | 招聘方已发出面试邀请，等待求职者接受或拒绝 |

## 筛选示例

### 查看 7 月全部面试

```http
GET /rc/companies/interviews?interview_at_from=2026-07-01 00:00:00&interview_at_to=2026-07-31 23:59:59
Authorization: Bearer {token}
```

### 查看某职位下已安排面试

```http
GET /rc/companies/interviews?job_id=678&status=1
Authorization: Bearer {token}
```

### 查看待候选人确认的面试邀请

```http
GET /rc/companies/interviews?status=4
Authorization: Bearer {token}
```

## 错误响应

### 未登录或 Token 无效

由 `auth:rc` 中间件返回，常见为 `401`。

```json
{
  "message": "Unauthenticated."
}
```

### 未切换招聘方身份或未绑定企业

```json
{
  "code": 422,
  "message": "请先切换为招聘方身份并绑定企业。"
}
```

## 前端接入建议

- 日历视图建议按 `interview_at` 分组展示。
- 使用 `status_label`、`mode_label` 直接展示中文，不要在前端重复维护枚举文案。
- 线上面试优先展示 `meeting_url`；没有链接时展示 `location`。
- 线下面试优先展示 `location`。
- 候选人信息优先从 `application.resume` 或 `application.candidate` 读取。
- 点击职位可跳转到 `application.job_id` 对应的职位详情。
- 点击投递可跳转到 `application.id` 对应的投递详情。
