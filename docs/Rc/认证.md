# 认证

## 说明

- 路由前缀：`/rc`
- 当前已注册认证接口：
  - `POST /rc/auth/send-verification-code`
  - `POST /rc/auth/phone-login`
  - `POST /rc/auth/email-login`
  - `POST /rc/auth/forgot-password`
- 返回格式：
  - 成功：`api_response()`，结构为 `code` + `data` + `meta`
  - 业务错误：`error()`，结构为 `code` + `message` + `meta`

---

## 1) 发送验证码

- 接口：`POST /rc/auth/send-verification-code`
- 描述：发送登录/找回密码验证码

### 请求参数

```json
{
  "type": "phone",
  "account": "13800138000",
  "scene": "login"
}
```

### 字段规则

- `type`：必填，`phone` 或 `email`
- `account`：必填，字符串，最大 100
- `scene`：必填，`login` 或 `forgot_password`

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例（发送频率限制）

```json
{
  "code": 429,
  "message": "发送过于频繁，请稍后再试。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

## 2) 手机号登录

- 接口：`POST /rc/auth/phone-login`
- 描述：验证码登录；若用户不存在会自动注册

### 请求参数

```json
{
  "phone": "13800138000",
  "code": "123456"
}
```

### 字段规则

- `phone`：必填，字符串，最大 30
- `code`：必填，6 位数字

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "token_type": "Bearer",
    "access_token": "<access-token>",
    "user": {
      "id": 1,
      "uuid": "7f3d1e62-1f16-4d20-9f8c-5f9f3f6ab123",
      "name": "用户名称",
      "nickname": null,
      "phone": "13800138000",
      "email": "",
      "gender": 0,
      "avatar": "",
      "last_login_ip": "127.0.0.1",
      "last_login_at": "2026-05-29 12:00:00",
      "current_identity": null
    }
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例（验证码错误）

```json
{
  "code": 422,
  "message": "验证码错误或已失效。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

## 3) 邮箱登录

- 接口：`POST /rc/auth/email-login`
- 描述：验证码登录；若用户不存在会自动注册

### 请求参数

```json
{
  "email": "test@example.com",
  "code": "123456"
}
```

### 字段规则

- `email`：必填，合法邮箱，最大 100
- `code`：必填，6 位数字

### 成功响应

- 结构同“手机号登录”成功响应。

### 业务失败响应

- 验证码错误或失效：同“手机号登录”失败响应。

---

## 4) 忘记密码

- 接口：`POST /rc/auth/forgot-password`
- 描述：验证码校验后重置密码

### 请求参数

```json
{
  "type": "email",
  "account": "test@example.com",
  "code": "123456",
  "password": "new-password",
  "password_confirmation": "new-password"
}
```

### 字段规则

- `type`：必填，`phone` 或 `email`
- `account`：必填，字符串，最大 100
- `code`：必填，6 位数字
- `password`：必填，且需满足默认密码强度规则
- `password_confirmation`：必填，必须与 `password` 一致

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

- 验证码错误或失效：

```json
{
  "code": 422,
  "message": "验证码错误或已失效。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

- 用户不存在：

```json
{
  "code": 422,
  "message": "用户不存在。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```
