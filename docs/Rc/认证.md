# 认证

## 说明

- 路由前缀：`/rc`
- 已注册认证接口：
  - `POST /rc/auth/send-verification-code`（无需鉴权）
  - `POST /rc/auth/phone-login`（无需鉴权）
  - `POST /rc/auth/email-login`（无需鉴权）
  - `POST /rc/auth/forgot-password`（无需鉴权）
  - `GET /rc/auth/me`（需 Bearer Token，`auth:rc`）
  - `POST /rc/auth/logout`（需 Bearer Token，`auth:rc`）
  - `POST /rc/auth/refresh-token`（需 Bearer Token，`auth:rc`）
- 返回格式：
  - 成功：`api_response()`，结构为 `code` + `data` + `meta`
  - 业务错误：`error()`，结构为 `code` + `message` + `meta`

## 公共数据结构

### 用户身份对象（UserIdentity）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 身份 ID |
| `user_id` | int | 所属用户 ID |
| `company_id` | int\|null | 关联企业 ID（招聘方身份） |
| `identity_type` | int | 身份类型，见下表 |
| `identity_name` | string | 身份名称 |
| `organization_name` | string\|null | 所属机构名称 |
| `job_title` | string\|null | 头衔/岗位名称 |
| `is_default` | int | 是否默认身份（`1` = 是，`0` = 否） |
| `status` | int | 状态（`1` = 启用，`0` = 停用） |
| `extra` | object\|null | 扩展字段（按身份类型不同而异） |
| `has_basic_info` | bool | 是否已填写基础信息 |

**`identity_type` 枚举值：**

| 值 | 含义 |
|----|------|
| `1` | 求职者 |
| `2` | 招聘方 |
| `3` | 校招负责人 |
| `4` | 政府机构负责人 |
| `5` | 猎头 |

### 登录/刷新令牌成功响应 `data` 结构

```json
{
  "token_type": "Bearer",
  "access_token": "<access-token>",
  "user": {
    "id": 1,
    "uuid": "7f3d1e62-1f16-4d20-9f8c-5f9f3f6ab123",
    "name": "用户名称",
    "nickname": null,
    "phone": "13800138000",
    "email": "",
    "gender": 0,
    "avatar": "",
    "last_login_ip": "127.0.0.1",
    "last_login_at": "2026-05-29 12:00:00",
    "current_identity": null,
    "identities": []
  }
}
```

- `current_identity`：当前生效的身份对象（UserIdentity），首次登录且未绑定任何身份时为 `null`。
- `identities`：该用户所有身份列表，按 `is_default DESC, id ASC` 排序，每项包含 `has_basic_info`。

## 1) 发送验证码

- 接口：`POST /rc/auth/send-verification-code`
- 描述：发送登录/找回密码验证码

### 请求参数

```json
{
  "type": "phone",
  "account": "13800138000",
  "scene": "login"
}
```

### 字段规则

- `type`：必填，`phone` 或 `email`
- `account`：必填，字符串，最大 100
- `scene`：必填，`login` 或 `forgot_password`

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例（发送频率限制）

```json
{
  "code": 429,
  "message": "发送过于频繁，请稍后再试。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123,
    "expires_in": 55
  }
}
```

> `meta.expires_in`：剩余冷却秒数，前端可据此显示倒计时。

## 2) 手机号登录

- 接口：`POST /rc/auth/phone-login`
- 描述：验证码登录；若用户不存在会自动注册

### 请求参数

```json
{
  "phone": "13800138000",
  "code": "123456"
}
```

### 字段规则

- `phone`：必填，字符串，最大 30
- `code`：必填，6 位数字

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "token_type": "Bearer",
    "access_token": "<access-token>",
    "user": {
      "id": 1,
      "uuid": "7f3d1e62-1f16-4d20-9f8c-5f9f3f6ab123",
      "name": "用户名称",
      "nickname": null,
      "phone": "13800138000",
      "email": "",
      "gender": 0,
      "avatar": "",
      "last_login_ip": "127.0.0.1",
      "last_login_at": "2026-05-29 12:00:00",
      "current_identity": null,
      "identities": []
    }
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例（验证码错误）

```json
{
  "code": 422,
  "message": "验证码错误或已失效。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

## 3) 邮箱登录

- 接口：`POST /rc/auth/email-login`
- 描述：验证码登录；若用户不存在会自动注册

### 请求参数

```json
{
  "email": "test@example.com",
  "code": "123456"
}
```

### 字段规则

- `email`：必填，合法邮箱（RFC + DNS 校验），最大 100；服务端会统一转小写
- `code`：必填，6 位数字

### 成功响应

- 结构同"手机号登录"成功响应。

### 业务失败响应

- 验证码错误或失效：同"手机号登录"失败响应。

## 4) 忘记密码

- 接口：`POST /rc/auth/forgot-password`
- 描述：验证码校验后重置密码

### 请求参数

```json
{
  "type": "email",
  "account": "test@example.com",
  "code": "123456",
  "password": "new-password",
  "password_confirmation": "new-password"
}
```

### 字段规则

- `type`：必填，`phone` 或 `email`
- `account`：必填，字符串，最大 100
- `code`：必填，6 位数字
- `password`：必填，需满足 Laravel 默认密码强度规则，且需通过 `password_confirmation` 确认
- `password_confirmation`：必填，必须与 `password` 一致

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

### 业务失败响应示例

- 验证码错误或失效：

```json
{
  "code": 422,
  "message": "验证码错误或已失效。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

- 用户不存在：

```json
{
  "code": 422,
  "message": "用户不存在。",
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

## 5) 获取当前用户

- 接口：`GET /rc/auth/me`
- 鉴权：Bearer Token（`auth:rc`）

### 成功响应示例

```json
{
  "code": 200,
  "data": {
    "user": {
      "id": 1,
      "uuid": "7f3d1e62-1f16-4d20-9f8c-5f9f3f6ab123",
      "name": "用户名称",
      "nickname": null,
      "phone": "13800138000",
      "email": "test@example.com",
      "gender": 0,
      "avatar": "",
      "last_login_ip": "127.0.0.1",
      "last_login_at": "2026-05-29 12:00:00",
      "current_identity": {
        "id": 1,
        "user_id": 1,
        "company_id": null,
        "identity_type": 1,
        "identity_name": "求职者",
        "organization_name": null,
        "job_title": null,
        "is_default": 1,
        "status": 1,
        "extra": null,
        "has_basic_info": false
      },
      "identities": [
        {
          "id": 1,
          "user_id": 1,
          "company_id": null,
          "identity_type": 1,
          "identity_name": "求职者",
          "organization_name": null,
          "job_title": null,
          "is_default": 1,
          "status": 1,
          "extra": null,
          "has_basic_info": false
        }
      ]
    }
  },
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

> `current_identity` 为 Token 创建时所关联的身份（通过 `responsible` 多态关联获取）；若 Token 未关联身份则为 `null`。

## 6) 退出登录

- 接口：`POST /rc/auth/logout`
- 鉴权：Bearer Token（`auth:rc`）
- 描述：撤销当前 Token，完成退出。

### 成功响应示例

```json
{
  "code": 200,
  "data": [],
  "meta": {
    "timestamp": 1748500000.1234,
    "response_time": 0.0123
  }
}
```

## 7) 切换/绑定身份（刷新令牌）

- 接口：`POST /rc/auth/refresh-token`
- 鉴权：Bearer Token（`auth:rc`）
- 描述：切换当前用户的默认身份，颁发新 Token，同时撤销旧 Token。若该身份不存在则自动创建。

### 请求参数

```json
{
  "identity_type": 1
}
```

### 字段规则

- `identity_type`：必填，整数，见公共数据结构中的 `identity_type` 枚举值表
