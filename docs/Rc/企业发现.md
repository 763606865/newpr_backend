# 企业发现（求职者）

## 说明

- 路由前缀：`/rc`
- 适用对象：求职者浏览企业主页、收藏企业
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`

---

## 公共数据结构

### 企业发现对象（`RcCompanyDiscoveryResource`）

面向求职者展示，不包含信用代码、法人、证件等敏感信息。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 企业 ID |
| `name` | string | 企业全称 |
| `display_name` | string | 展示名称（优先 `profile.short_name`） |
| `address` | string\|null | 企业地址 |
| `city_name` | string\|null | 主办公城市全称（由 `profile.city_code` 推导） |
| `profile` | object\|null | 招聘展示资料，结构见 [企业.md](./企业.md) 中「企业资料对象」 |
| `albums` | array | 企业相册列表，结构见 [企业.md](./企业.md) 中「企业相册对象」；仅返回启用图片 |
| `stat` | object | 统计信息 |
| `stat.public_jobs` | int | 当前在招职位数 |

### 职位列表

企业详情中的 `jobs` 为 Laravel 分页结构，条目使用 `RcJobResource`（含 `position`）。

登录用户时，职位列表项额外返回：

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_applied` | bool | 当前用户是否已投递该职位 |
| `is_favorited` | bool | 当前用户是否已收藏该职位 |

## 1) 推荐企业列表

- 接口：`GET /rc/talent/companies/recommend`
- 描述：推荐当前城市下有公开在招职位的企业，优先名企、公开职位数更多的企业
- 鉴权：可选 `Bearer Token`（登录后会排除当前求职者企业黑名单中的企业）

### Query 参数

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `per_page` | 否 | 每页条数，默认 15，最大 100 |
| `city_code` | 否 | 城市编码；不传时会读取 `X-City-Code` 请求头 |

### 成功响应 `data`

Laravel 分页对象；`data.data[]` 为企业发现对象，额外包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `recommendation.strategy` | string | 推荐策略 |
| `recommendation.city_code` | string\|null | 推荐使用的城市编码 |

## 2) 搜索企业列表

- 接口：`GET /rc/talent/companies`
- 描述：搜索可展示企业列表，返回企业基础资料、相册和公开职位数
- 鉴权：需 `Bearer Token` + 求职者身份

### Query 参数

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `per_page` | 否 | 每页条数，默认 15，最大 100 |
| `keyword` | 否 | 企业名称、企业简称或企业简介关键词 |
| `city_code` | 否 | 主办公城市编码 |
| `industry_code` | 否 | 行业 code |
| `scale_type` | 否 | 公司规模 |
| `nature_type` | 否 | 公司性质 |

### 成功响应 `data`

Laravel 分页对象；`data.data[]` 为企业发现对象。

### 业务失败

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为求职者身份。 |

## 3) 企业详情页

- 接口：`GET /rc/talent/companies/{id}`
- 描述：查看企业公开资料及在招职位列表
- 鉴权：可选 `Bearer Token`（`auth:rc`）

### 路径参数

| 字段 | 说明 |
|------|------|
| `id` | 企业 ID |

### Query 参数

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `per_page` | 否 | 职位列表每页条数，默认 15，最大 100 |

### 可见规则

- 仅返回 `status = 启用` 的企业
- 职位列表仅包含已发布且未过期的职位
- 禁用、审批中、已删除企业返回 `404`

### 登录用户额外字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_favorited` | bool | 当前用户是否已收藏该企业 |

未登录时不返回 `is_favorited`。

## 4) 企业公开职位列表

- 接口：`GET /rc/talent/companies/{id}/jobs`
- 描述：返回指定企业已发布且未过期的职位列表，支持分页和常用筛选
- 鉴权：需 `Bearer Token`

### 路径参数

| 字段 | 说明 |
|------|------|
| `id` | 企业 ID |

### Query 参数

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `per_page` | 否 | 每页条数，默认 15，最大 100 |
| `employment_type` | 否 | 职位类型 |
| `experience_min` | 否 | 最低工作经验筛选 |
| `experience_max` | 否 | 最高工作经验筛选 |
| `salary_min` | 否 | 最低薪资筛选 |
| `salary_max` | 否 | 最高薪资筛选 |
| `city_code` | 否 | 工作地点城市编码 |

### 成功响应 `data`

Laravel 分页对象；`data.data[]` 为 `RcJobResource`。

登录用户时，职位列表项额外返回：

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_applied` | bool | 当前用户是否已投递该职位 |
| `is_favorited` | bool | 当前用户是否已收藏该职位 |

### 业务失败

| `code` | `message` |
|--------|-----------|
| `404` | 企业不存在或不可查看。 |

## 5) 我收藏的企业列表

- 接口：`GET /rc/talent/favorites/companies`
- 描述：返回当前求职者收藏的企业列表，按收藏时间倒序
- 鉴权：需 `Bearer Token` + 求职者身份

完整字段说明见 [收藏.md](./收藏.md)。

---

## 6) 收藏企业

- 接口：`POST /rc/talent/companies/{id}/favorite`
- 描述：收藏指定企业
- 鉴权：需 `Bearer Token` + 求职者身份

### 成功响应

```json
{
  "code": 200,
  "data": {
    "is_favorited": true
  }
}
```

### 业务失败

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为求职者身份。 |
| `404` | 企业不存在或不可查看。 |

> 重复收藏为幂等操作，仍返回 `is_favorited = true`。

---

## 7) 取消收藏企业

- 接口：`DELETE /rc/talent/companies/{id}/favorite`
- 描述：取消收藏指定企业
- 鉴权：需 `Bearer Token` + 求职者身份

### 成功响应

```json
{
  "code": 200,
  "data": {
    "is_favorited": false
  }
}
```

### 业务失败

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为求职者身份。 |
| `404` | 企业不存在或不可查看。 |

## 前端推荐流程

1. 首页或推荐位调用 `GET /rc/talent/companies/recommend`
2. 搜索页调用 `GET /rc/talent/companies`
3. 从职位详情或搜索结果进入 `GET /rc/talent/companies/{id}`
4. 展示 `company.profile` 与企业简介、在招职位列表 `jobs.data`
5. 需要单独分页或筛选职位时，调用 `GET /rc/talent/companies/{id}/jobs`
6. 登录用户根据 `is_favorited` 渲染收藏按钮
7. 收藏 / 取消收藏分别调用 `POST` / `DELETE /rc/talent/companies/{id}/favorite`

## 相关收藏接口

完整说明见 [收藏.md](./收藏.md)。

| 对象 | 列表 | 收藏 | 取消收藏 | 适用身份 |
|------|------|------|----------|----------|
| 企业 | `GET /rc/talent/companies` / `GET /rc/talent/favorites/companies` | `POST /rc/talent/companies/{id}/favorite` | `DELETE /rc/talent/companies/{id}/favorite` | 求职者 |
| 职位 | `GET /rc/talent/favorites/jobs` | `POST /rc/talent/jobs/{id}/favorite` | `DELETE /rc/talent/jobs/{id}/favorite` | 求职者 |
| 简历 | `GET /rc/talent/favorites/resumes` | `POST /rc/talent/resumes/{id}/favorite` | `DELETE /rc/talent/resumes/{id}/favorite` | 招聘方（当前企业） |

详情页均返回 `is_favorited` 字段供前端回显收藏状态。
