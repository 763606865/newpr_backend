# 招聘公告（求职者）

聚合型校招/社招/实习招聘公告，数据来源于 `rc_announcements`。列表项以**官网外链**为主，平台内不提供投递，前端通过 `link_url` 跳转或复制链接。

> 门户 CMS 侧「系统公告 / 政策公告」见 [公告页.md](../Cms/公告页.md)；本接口面向 RC 求职者端的**结构化招聘公告**。

---

## 说明

- 路由前缀：`/rc`
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`
- 搜索引擎：Laravel Scout + Elasticsearch（索引名 `rc_announcements`）
- 无 `keyword` 时走数据库查询；有 `keyword` 时走 ES 全文检索

### 与平台内职位的区别

| 对比项 | `GET /rc/talent/jobs` | `GET /rc/talent/announcements` |
|--------|------------------------|--------------------------------|
| 数据类型 | 企业入驻后发布的在招职位 | 聚合的外部/官方招聘公告 |
| 投递 | 支持平台内投递 | **不支持**，仅外链 `link_url` |
| 发布方 | 绑定 `company_id` | `publisher_name` + `publisher_type` |
| 工作地点 | 单城市 `city_code` | 多城市 + `is_nationwide`（全国） |
| 工作类型 | 单值 `employment_type` | 多值 `employment_types` |

## 公共数据结构

### 公告对象（`RcAnnouncementResource`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 公告 ID |
| `title` | string | 标题 |
| `sub_title` | string\|null | 副标题 |
| `publisher_name` | string\|null | 发布人/企业名称 |
| `publisher_type` | int | 发布人类型，见 [CmsAnnouncementPublisherType](#cmsannouncementpublishertype) |
| `publisher_type_label` | string\|null | 发布人类型文案 |
| `announcement_type` | int\|null | 公告业务类型，见 [RcAnnouncementType](#rcannouncementtype) |
| `announcement_type_label` | string\|null | 公告业务类型文案 |
| `cover` | string\|null | 推广图 OSS 路径 |
| `display_cover` | string\|null | 推广图展示 URL（同 `cover` 解析结果） |
| `summary` | string\|null | 摘要 |
| `content` | string\|null | 公告正文，仅详情接口返回，可能包含 HTML |
| `link_url` | string\|null | **官网外链**（主跳转地址） |
| `registration_url` | string\|null | 报名入口地址，与公告原文地址分开 |
| `attachments` | array | 公告附件列表，元素包含 `name` 和 `url`；无附件时为 `[]` |
| `employment_types` | array\<int\> | 工作类型值列表，见 [RcJobEmploymentType](#rcjobemploymenttype) |
| `employment_type_labels` | array\<string\> | 工作类型文案列表 |
| `graduation_years` | array\<int\> | 面向届别，如 `[2026, 2027]` |
| `graduation_year_labels` | array\<string\> | 届别展示文案，如 `["2026届", "2027届"]` |
| `education_level` | int\|null | 最低学历，见 [RcEducationLevel](#rceducationlevel) |
| `education_level_label` | string\|null | 学历文案 |
| `major_requirement` | string\|null | 专业要求说明（展示用） |
| `recruitment_count` | int\|null | 招录或招聘人数；“若干”等非数字人数时为 `null` |
| `major_codes` | array\<string\> | 关联专业国标编码（预加载 `majors` 时返回） |
| `major_names` | array\<string\> | 关联专业名称 |
| `is_nationwide` | bool | 是否全国招聘 |
| `location_label` | string\|null | 地点展示：`全国`，或城市名拼接（如 `苏州、济南`） |
| `city_codes` | array\<string\> | 工作城市编码（预加载 `cities` 时返回；全国时为 `[]`） |
| `city_names` | array\<string\> | 工作城市名称 |
| `apply_start_at` | string\|null | 报名开始时间 |
| `apply_end_at` | string\|null | 报名截止时间（`apply_deadline_type=2` 时通常为 `null`） |
| `apply_deadline_type` | int | 截止类型，见 [RcAnnouncementApplyDeadlineType](#rcannouncementapplydeadlinetype) |
| `apply_deadline_type_label` | string\|null | 截止类型文案 |
| `apply_status` | string | 报名状态：`正在报名` / `即将截止` / `已截止`（计算字段） |
| `published_at` | string\|null | 发布时间 |
| `expired_at` | string\|null | 失效时间 |
| `is_top` | bool | 是否置顶 |
| `source_name` | string\|null | 来源名称 |
| `source_url` | string\|null | 来源地址 |
| `read_count` | int | 阅读人数 |
| `display_fields` | object | 扩展展示字段；不会返回第三方原始数据，详情见下表 |
| `tags` | array | 标签列表（预加载 `tags` 时返回），元素含 `id`、`name`、`slug`、`category` |
| `created_at` | string\|null | 创建时间 |
| `updated_at` | string\|null | 更新时间 |

`display_fields` 当前可能包含以下展示属性。字段可能因公告来源不同而缺失，客户端应按可选字段处理：

| 字段 | 类型 | 说明 |
|------|------|------|
| `hire_count_text` | string\|null | 招聘人数展示文本，例如 `50` 或 `若干` |
| `region` | string\|null | 第三方公告中的原始地区文案 |
| `industry` | string\|null | 行业领域 |
| `positions_number` | int\|null | 招聘岗位数量 |
| `special_recruitment` | bool\|null | 是否专项招聘 |
| `is_hot` | bool\|null | 是否热门公告 |
| `has_establishment` | bool\|null | 是否有编制 |
| `publish_year` | string\|null | 公告年份 |
| `public_all_type` | string\|null | 第三方展示类型，例如“招满为止” |

> `extra` 及 `extra.cjwl` 属于服务端内部数据，不通过公开接口返回。

### 列表分页

列表接口 `data` 为 Laravel 分页结构：`data`（条目数组）、`total`、`per_page`、`current_page`、`last_page` 等。

### 与推荐接口的区别

| 对比项 | `GET /rc/talent/announcements` | `GET /rc/talent/announcements/recommend` |
|--------|--------------------------------|------------------------------------------|
| 鉴权 | 必须登录 + 求职者身份 | **可选登录** |
| 筛选来源 | 用户主动传 Query 参数 | 系统按策略推导筛选条件 |
| 响应额外字段 | 无 | `data.recommendation`（策略与已应用筛选） |

## 1) 推荐招聘公告

- 接口：`GET /rc/talent/announcements/recommend`
- 描述：按推荐策略返回**正在报名**的招聘公告，无需登录；登录且填写求职意向时自动切换策略
- 鉴权：可选 `Bearer Token`（`auth:rc`）

### 推荐策略

| 策略 | 触发条件 | 筛选规则 |
|------|----------|----------|
| `guest_local` | 未登录，或已登录但无有效求职意向 | 当前城市（`city_code`）+ 仅 `apply_open=1` |
| `intention` | 已登录，且主简历存在有效求职意向 | 意向城市、工作类型、学历、应届届别 + 仅正在报名 |

有效求职意向：至少填写**期望城市**或**工作类型**中的一项。

`intention` 策略额外规则：

- 学历：取主简历 `highest_education_level`
- 届别：主简历 `is_fresh_graduate=1` 时，默认匹配当前自然年

### Query 参数

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `city_code` | 否 | 当前城市（市级区划 `code`）；未登录时建议必传，也可通过 Header `X-City-Code` 传递 |
| `per_page` | 否 | 每页条数，默认 `15`，最大 `100` |

### 成功响应补充字段

分页结构同搜索接口，额外包含：

| 字段 | 说明 |
|------|------|
| `data.recommendation.strategy` | 本次策略：`guest_local` / `intention` |
| `data.recommendation.applied_filters` | 实际传给搜索引擎的筛选条件 |
| `data.recommendation.sort` | 排序规则（`is_top desc` → `sort asc` → `published_at desc`） |

### 请求示例

```http
GET /rc/talent/announcements/recommend?city_code=360100&per_page=15
X-City-Code: 360100
```

## 2) 搜索招聘公告

- 接口：`GET /rc/talent/announcements`
- 描述：求职者按关键词与条件搜索已发布公告
- 鉴权：需 `Bearer Token` + 求职者身份（`identity_type = 1`）

### Query 参数

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `keyword` | 否 | 全文搜索关键词 |
| `city_code` | 否 | 工作城市编码（市级 `code`，来源 `GET /rc/meta/areas`）；匹配该城市或 `is_nationwide=1` 的全国公告 |
| `employment_type` | 否 | 工作类型，见 [RcJobEmploymentType](#rcjobemploymenttype)；公告 `employment_types` 包含该值即命中 |
| `education_level` | 否 | 最低学历，见 [RcEducationLevel](#rceducationlevel) |
| `graduation_year` | 否 | 面向届别年份，如 `2026` |
| `major_code` | 否 | 专业国标编码，来源 `GET /rc/meta/majors` 中 `full_code` |
| `publisher_type` | 否 | 发布人类型（单值） |
| `publisher_types` | 否 | 发布人类型列表，支持 `publisher_types[]=2&publisher_types[]=14` 或逗号分隔 |
| `tag_ids` | 否 | 标签 ID 列表，标签选项见 `GET /cms/meta/tags` |
| `tags_match_all` | 否 | 标签匹配方式，默认 `false`（任一命中）；传 `true` / `1` 时须同时包含全部 `tag_ids` |
| `apply_open` | 否 | 传 `true` / `1` 时仅返回正在报名的公告 |
| `per_page` | 否 | 每页条数，默认 `15`，最大 `100` |

### 关键词匹配范围

`keyword` 会在 ES 索引中检索，主要包括：

| 分类 | 匹配内容 |
|------|----------|
| 基本信息 | `title`、`sub_title`、`summary`、`content` |
| 发布方 | `publisher_name`、`source_name` |
| 地点 | `city_names`、`city_codes` |
| 专业 | `major_names`、`major_codes`、`major_requirement` |
| 标签 | `tag_names`、`tag_slugs`、`tags` |
| 类型文案 | `employment_type_labels`、`graduation_year_labels`、`publisher_type_label` |

### 公开可见规则

仅满足以下条件的公告会出现在结果中：

- `status = 2`（已发布）
- `expired_at` 为空，或未过期

草稿、下线、已失效公告不会返回。

### 排序规则

默认：`is_top desc` → `sort asc` → `published_at desc`

### 请求示例

```http
GET /rc/talent/announcements?city_code=320500&employment_type=4&graduation_year=2026&apply_open=1
Authorization: Bearer {token}
```

```http
GET /rc/talent/announcements?keyword=中粮&publisher_types=2,14&tag_ids=5,8
Authorization: Bearer {token}
```

### 业务错误

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为求职者身份。 |

### 规则

- 须先通过 `POST /rc/auth/refresh-token` 切换为求职者身份

- `apply_status` 为服务端计算字段，可用于列表角标（正在报名 / 即将截止 / 已截止）

## 3) 招聘公告详情

- 接口：`GET /rc/talent/announcements/{id}`
- 描述：根据公告 ID 获取已发布且未失效的招聘公告详情
- 鉴权：无需登录

每次成功获取详情都会将该公告的 `read_count` 原子增加 `1`，响应中的 `read_count` 已包含本次访问。不存在、已下架或已失效的公告不会增加阅读量。

### Path 参数

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| `id` | int | 是 | 招聘公告 ID，仅支持正整数 |

### 公开可见规则

仅满足以下条件的公告可以查看：

- `status = 2`（已发布）
- `expired_at` 为空，或大于等于当前时间

草稿、已下架、已失效或不存在的公告统一返回业务错误 `404`。

### 响应字段

返回单个[公告对象](#公告对象rcannouncementresource)，并额外返回：

| 字段 | 类型 | 说明 |
|------|------|------|
| `content` | string\|null | 公告正文，可能包含 HTML，前端展示时应进行安全渲染 |

详情接口会预加载城市、专业和标签，因此正常响应中会包含 `city_codes`、`city_names`、`major_codes`、`major_names` 和 `tags` 等关联字段。

GET /rc/talent/announcements/1

## 前端推荐流程

1. 首页未登录：`GET /rc/talent/announcements/recommend?city_code=360100` 展示本地正在报名的公告
2. 登录后：`POST /rc/auth/refresh-token` 切换求职者身份
3. 完善简历与求职意向后：继续调用推荐接口（自动走 `intention` 策略）
4. 主动筛选：加载 `GET /rc/meta/areas`、`GET /rc/meta/majors`、`GET /cms/meta/tags` 后调用 `GET /rc/talent/announcements`
5. 用户点击公告：调用 `GET /rc/talent/announcements/{id}` 查看站内详情；需要访问官网时跳转或复制 `link_url`
