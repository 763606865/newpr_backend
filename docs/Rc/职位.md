# 职位（招聘方发布/管理）

## 说明

- 路由前缀：`/rc`
- 鉴权：均需 `Bearer Token`，并使用 `auth:rc`
- 适用对象：招聘方身份（`identity_type = 2`），且当前 Token 关联身份已绑定企业（`organization_type = company`）
- 数据范围：仅能操作 **当前绑定企业** 下的职位
- 成功响应：`api_response()`，结构为 `code` + `data` + `meta`
- 业务错误：`error()`，结构为 `code` + `message` + `meta`

### 与前端表单字段对应

| 表单区域 | 接口字段 | 说明 |
|----------|----------|------|
| 工作性质 | `employment_type` | 见 [RcJobEmploymentType](#rcjobemploymenttype) |
| 职位名称 | `title` | 必填 |
| 职位描述 | `description` | 最长 10000 字；发布时必填 |
| 职位类别 | `position_code` | 对应 `GET /rc/meta/positions` 中 `code` |
| 最低学历 | `education_level` | 见 [RcEducationLevel](#rceducationlevel)；发布时必填 |
| 工作经验 | `experience_min` / `experience_max` | 经验年限（年），可选 |
| 薪资范围 | `salary_min` / `salary_max` / `salary_unit` | 可选；`salary_unit` 默认 `1`（月） |
| 职位关键词 | `keywords` | 字符串数组，最多 20 个，写入 `extra.keywords` |
| 工作地址 | `workplace` | 发布时必填；`city_code` 可选（市级区划 code） |
| 招聘人数 | `headcount` | 默认 `1`；发布时必填 |
| 对求职者展示 | `show_headcount` | 布尔，写入 `extra.show_headcount`，默认 `true` |

## 1) 职位列表

- 接口：`GET /rc/jobs`
- 描述：当前企业职位列表，按更新时间倒序

### Query 参数

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `status` | 否 | 按状态筛选，见 [RcJobStatus](#rcjobstatus) |
| `employment_type` | 否 | 按用工类型筛选 |
| `keyword` | 否 | 全文搜索（标题、职位编码、描述、要求、福利、关键词、企业名等）；传此参数时走 Scout 搜索引擎 |
| `per_page` | 否 | 每页条数，默认 15，最大 100 |

### 业务错误

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为招聘方身份并绑定企业。 |

---

## 2) 职位详情

- 接口：`GET /rc/jobs/{id}`

### 业务错误

| `code` | `message` |
|--------|-----------|
| `422` | 请先切换为招聘方身份并绑定企业。 |
| `404` | 职位不存在。 |

## 3) 创建职位

- 接口：`POST /rc/jobs`
- 描述：创建草稿或直接发布（传 `status = 1`）

### 请求参数

| 字段 | 是否必填 | 规则 | 说明 |
|------|----------|------|------|
| `title` | 是 | `required`, `string`, `max:255` | 职位名称 |
| `employment_type` | 是 | `required`, 枚举 | 工作性质 |
| `position_code` | 是 | `required`, 存在于 `rc_positions.code` | 职位类别 |
| `description` | 否 | `nullable`, `string`, `max:10000` | 职位描述 |
| `requirement` | 否 | `nullable`, `string`, `max:10000` | 职位要求 |
| `benefit` | 否 | `nullable`, `string`, `max:10000` | 福利待遇 |
| `education_level` | 否 | 枚举 | 最低学历 |
| `experience_min` / `experience_max` | 否 | `integer`, `0-50` | 经验年限 |
| `salary_min` / `salary_max` | 否 | `numeric`, `>=0` | 薪资 |
| `salary_unit` | 否 | 枚举 | 薪资单位，默认月 |
| `city_code` | 否 | 有效市级 `areas.code` | 工作城市 |
| `workplace` | 否 | `string`, `max:255` | 工作地址 |
| `headcount` | 否 | `integer`, `1-9999` | 招聘人数，默认 1 |
| `keywords` | 否 | `array`, 最多 20 项 | 职位关键词 |
| `show_headcount` | 否 | `boolean` | 对求职者展示招聘人数 |
| `status` | 否 | 枚举，默认 `0`（草稿） | 传 `1` 表示创建并发布 |
| `expired_at` | 否 | `date` | 过期时间 |
| `department_id` | 否 | `exists:departments,id` | 部门 |

### 请求示例（发布）

```json
{
  "title": "高级后端工程师",
  "employment_type": 1,
  "position_code": "backend-developer",
  "description": "负责核心业务系统研发……",
  "education_level": 3,
  "experience_min": 3,
  "experience_max": 5,
  "salary_min": 15000,
  "salary_max": 25000,
  "salary_unit": 1,
  "workplace": "南昌市高新区示例路 88 号",
  "headcount": 2,
  "keywords": ["Java", "Laravel", "MySQL"],
  "show_headcount": true,
  "status": 1
}
```

### 发布校验（`status = 1` 或调用发布接口时）

须已填写：`title`、`position_code`、`description`、`workplace`、`education_level`，且 `headcount >= 1`。

### 业务错误（发布字段不全）

| `code` | `message` 示例 |
|--------|----------------|
| `422` | 请填写职位描述。 |
| `422` | 请输入工作地址。 |
| `422` | 请选择最低学历。 |

---

## 4) 更新职位

- 接口：`PUT /rc/jobs/{id}`
- 描述：部分更新；若将 `status` 设为 `1` 且尚未发布，则同时执行发布校验

### 请求参数

字段同创建，均为可选（`sometimes`）。

---

## 5) 发布职位

- 接口：`POST /rc/jobs/{id}/publish`
- 描述：将草稿发布为「已发布」，写入 `published_at`

### 业务错误

| `code` | `message` |
|--------|-----------|
| `422` | 职位已发布，无需重复操作。 |
| `422` | 请填写职位名称。 / 请选择职位类别。 / …（发布校验） |

---

## 6) 暂停职位

- 接口：`POST /rc/jobs/{id}/pause`
- 描述：状态设为「暂停」（`2`）

---

## 7) 关闭职位

- 接口：`POST /rc/jobs/{id}/close`
- 描述：状态设为「关闭」（`3`）

---

## 8) 删除职位

- 接口：`DELETE /rc/jobs/{id}`
- 描述：软删除

### 成功响应

```json
{
  "code": 200,
  "data": [],
  "meta": { }
}
```

---

## 前端推荐流程

1. `POST /rc/auth/refresh-token` 切换招聘方身份（`identity_id` 指向已绑定企业的身份行）
2. `GET /rc/meta/positions` 加载职位类别树
3. `POST /rc/jobs` 保存草稿，或带 `status: 1` 直接发布
4. `GET /rc/jobs` 管理列表；`GET /rc/jobs/{id}` 编辑回显
5. 草稿完善后 `POST /rc/jobs/{id}/publish`
